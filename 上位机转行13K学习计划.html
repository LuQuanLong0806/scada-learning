〇、看文档前先认这 3 类东西（不然会云里雾里）

C# 世界里「写出来能跑的东西」分三类来源。本讲义每个 Day 开头都会先列一张「今天用到的技术从哪来」，请对照看——分清"天生物 / 类库 / 要装包"，你就不会迷糊了。

  • 🟦 【C# 语法】 = 语言自带的关键字/写法。装好 .NET 就有，不用装任何包。 例：using、class、int、string、var、=> （对照 TS：let/const → var；: type → 类型写在前面；function → 方法）
  • 🟩 【.NET 类库 / BCL】 = 微软随 .NET 提供的"标准零件库"，using 对应命名空间即可用，默认不用额外装包。 少数（如 SerialPort）需要加一行 dotnet add package System.IO.Ports 才能用——但它仍是微软官方库，不是第三方，只是被拆成了独立包。 例：Console、List<T>、Dictionary、Math、Task、HttpClient、System.Text.Json、LINQ（using System.Linq;）
  • 🟧 【第三方 NuGet 包】 = 别人（或微软但独立发布）写好的库，必须 dotnet add package 包名 安装后才能 using 使用，不在 .NET 默认里。 例：NModbus、S7.Net、LiveCharts、Serilog、MQTTnet、EF Core（Microsoft.EntityFrameworkCore） → 看到 using Xxx; 但报错"找不到类型/命名空间"，十有八九是要装 NuGet 包了。

💡 记忆口诀：语法天生物、BCL 随 .NET、第三方要装包。

Day 1 — 环境 + 第一个程序 + C# 与 TS 对比

🎯 目标：装好环境，跑出第一个 C# 程序，建立「C# = 强类型 TS」的直觉。

📌 今天用到的技术从哪来 | 写法 | 来源 | 对照 / 说明 | |---|---|---| | using System; | 🟦语法 + 命名空间 | 引入系统库，类比 TS 的 import | | class / Program.cs | 🟦语法 | 类与程序入口文件 | | int / string / double | 🟦语法 | 基础类型关键字（类型写在前面） | | Console.WriteLine/Write/ReadLine | 🟩.NET 类库 | 控制台输入输出，BCL 自带 | | int.Parse(...) | 🟩.NET 类库 | 字符串转数字，BCL 自带 | | $"..." 字符串插值 | 🟦语法 | 类比 JS 模板字符串 `...${}` | | dotnet new / dotnet run | ⚙️.NET SDK 命令 | 不是 C# 代码，是终端命令（类比 npm init / npm start） |

📖 通俗讲解 - C# 是微软的编程语言，运行在 .NET 平台上。你可以把它想成「加了严格类型的 TypeScript」。 - TypeScript 里你写 let x: number = 1;，C# 里写 int x = 1;（类型写在前面）。 - TypeScript 用 Node/npm 跑，C# 用 .NET 跑：dotnet new console 相当于 npm init，dotnet run 相当于 npm start。 - Program.cs 是程序入口，Console.WriteLine("文字") 就是 console.log("文字")。

💡 关键代码

// Program.cs
using System;

Console.WriteLine("Hello 上位机！");

// 输入两个数，输出和
Console.Write("输入第一个数：");
int a = int.Parse(Console.ReadLine()!);
Console.Write("输入第二个数：");
int b = int.Parse(Console.ReadLine()!);
Console.WriteLine($"和是：{a + b}");

✏️ 练习 1. 安装 .NET 8 SDK + Visual Studio 2022 社区版（免费）。 2. 新建控制台项目，把输出改成 Hello，我是{你的名字}。 3. 写一个程序：让用户输入两个数，输出它们的和。 4. （挑战）写一个程序：输入半径，输出圆面积（3.14 × r × r）。

✅ 答案 - 练习 2：Console.WriteLine("Hello，我是张三"); - 练习 3：见上方关键代码。 - 练习 4：

Console.Write("输入半径：");
double r = double.Parse(Console.ReadLine()!);
double area = 3.14 * r * r;
Console.WriteLine($"圆面积：{area}");

Day 2 — 类型系统（值类型 / 引用类型）

🎯 目标：搞懂 C# 里「值」和「引用」的区别，这是和 JS/TS 最大不同之一。

📌 今天用到的技术从哪来 | 写法 | 来源 | 说明 | |---|---|---| | struct / class | 🟦语法 | 值类型 / 引用类型关键字 | | int / bool / string | 🟦语法 | 基础类型 | | var x = 10; | 🟦语法 | 类型推断（写起来像 JS，仍是强类型） | | int? 可空类型 | 🟦语法 | 类比 TS 的 number \| null | | new Point { ... } 对象初始化器 | 🟦语法 | 创建对象并赋值的简写 | | .HasValue / .Value | 🟩.NET 类库 | 可空类型的成员（BCL 自带） |

📖 通俗讲解 - 值类型（int、double、bool、struct）：像两张纸上各写一个数，改一张不影响另一张。赋值 = 复制一份。 - 引用类型（class、string、数组）：像两张便利贴写同一个抽屉的编号，改抽屉里的内容，两张便利贴看到的都变。 - var 让编译器自动推断类型：var x = 10; 等价于 int x = 10;（写起来像 JS，但仍是强类型）。 - 可空类型：int? age = null; 表示「可能没有值」，对应 TS 的 number | null。

💡 关键代码

struct Point { public int X; public int Y; } // 值类型

Point p1 = new Point { X = 1, Y = 2 };
Point p2 = p1;      // 复制了一份
p2.X = 99;
Console.WriteLine(p1.X); // 输出 1（p1 没变）

class Person { public string Name = ""; } // 引用类型
Person a = new Person { Name = "张三" };
Person b = a;       // 同一个对象
b.Name = "李四";
Console.WriteLine(a.Name); // 输出 李四（a 也变了）

✏️ 练习 1. 用 struct 定义一个 Point（含 X、Y），演示值类型赋值互不影响。 2. 用 class 定义一个 Student（含 Name），演示引用类型赋值共享。 3. 声明一个可空 int：int? score = null;，判断它是否有值并打印。

✅ 答案

struct Point { public int X; public int Y; }
class Student { public string Name = ""; }

// 3.
int? score = null;
if (score.HasValue) Console.WriteLine(score.Value);
else Console.WriteLine("没有分数");

Day 3 — 集合与 LINQ

🎯 目标：用 List/Dictionary，并用 LINQ 把前端数组方法「翻译」成 C#。

📌 今天用到的技术从哪来 | 写法 | 来源 | 对照 | |---|---|---| | List<T> / Dictionary<K,V> | 🟩.NET 类库 | 集合类型，BCL 自带（类比 JS 数组 / 对象） | | using System.Linq; | 🟩.NET 类库（命名空间） | LINQ 在这里 | | .Select / .Where / .Sum / .First | 🟩.NET 类库 + LINQ | 类比 map / filter / reduce / find | | => Lambda | 🟦语法 | 类比 JS 箭头函数 | | .ToList() / .Average() | 🟩.NET 类库 + LINQ | 集合扩展方法 |

📖 通俗讲解 | 前端（JS） | C#（LINQ） | 作用 | |---|---|---| | arr.map(x=>x*2) | list.Select(x=>x*2) | 转换 | | arr.filter(x=>x>3) | list.Where(x=>x>3) | 过滤 | | arr.reduce(...) | list.Sum()/Aggregate() | 聚合 | | arr.find(...) | list.First(x=>...) | 查找 |

LINQ 是「对集合做查询的语言集成查询」，写起来像写 SQL，但作用在内存里的集合上。

💡 关键代码

using System.Linq;
var nums = new List<int> { 1, 2, 3, 4, 5 };
var doubled = nums.Select(x => x * 2).ToList();        // [2,4,6,8,10]
var big = nums.Where(x => x > 2).ToList();             // [3,4,5]
var sum = nums.Sum();                                   // 15
var dict = new Dictionary<string, int> { ["张三"] = 90, ["李四"] = 80 };
Console.WriteLine(dict["张三"]); // 90

✏️ 练习 1. 有一个 List<int>{10,20,30,40}，用 LINQ 算出所有大于 15 的数的和。 2. 用 Dictionary 存 3 个学生的成绩，打印平均分。 3. （挑战）把一个字符串列表里长度 > 2 的挑出来并转大写。

✅ 答案

var nums = new List<int> { 10, 20, 30, 40 };
int s = nums.Where(x => x > 15).Sum(); // 90

var scores = new Dictionary<string, int> { ["A"] = 90, ["B"] = 80, ["C"] = 70 };
double avg = scores.Values.Average();  // 80

var names = new List<string> { "ab", "cat", "go" };
var r = names.Where(n => n.Length > 2).Select(n => n.ToUpper()).ToList(); // ["CAT"]

Day 4 — 类与对象（class）

🎯 目标：用 class 封装数据和行为，对照 TS 的 class。

📌 今天用到的技术从哪来 | 写法 | 来源 | 对照 | |---|---|---| | class / public / void | 🟦语法 | 类、访问修饰符、无返回值 | | { get; set; } 属性 | 🟦语法 | 类比 TS 的 get/set 或 public 字段 | | public Car(int speed) 构造函数 | 🟦语法 | 类比 TS constructor | | static | 🟦语法 | 属于类本身（如 Math.PI、Console） | | => 表达式体方法 | 🟦语法 | 方法简写，类比箭头函数 | | new Car(120) { Brand = ... } | 🟦语法 | 构造 + 对象初始化器 |

📖 通俗讲解 - class 是「模板」，对象是「按模板造出来的具体东西」。比如 class 汽车 是模板，我的车是对象。 - 属性 public int Speed { get; set; } 对照 TS 的 get/set 或 public 字段，但更规范。 - 构造函数 public Car(int speed) 是「造对象时必做的初始化」，对照 TS 的 constructor。 - static 属于「类本身」而不是某个对象，比如 Math.PI、Console.WriteLine。

💡 关键代码

class Car
{
    public int Speed { get; set; }      // 属性
    public string Brand { get; set; } = "";
    public Car(int speed) { Speed = speed; } // 构造函数
    public void Show() => Console.WriteLine($"{Brand} 速度 {Speed}");
    public static int Wheels = 4;       // static 属于类
}

var c = new Car(120) { Brand = "比亚迪" };
c.Show();                   // 比亚迪 速度 120
Console.WriteLine(Car.Wheels); // 4

✏️ 练习 1. 定义一个 Student 类，含 Name、Age 属性和一个 SayHi() 方法打印问候。 2. 写构造函数，创建对象时直接赋值 Name。 3. 加一个 static 字段 School，所有学生共享。

✅ 答案

class Student
{
    public string Name { get; set; } = "";
    public int Age { get; set; }
    public static string School = "北大青鸟";
    public Student(string name) { Name = name; }
    public void SayHi() => Console.WriteLine($"你好，我是{Name}，{Age}岁");
}
var s = new Student("小明") { Age = 18 };
s.SayHi();
Console.WriteLine(Student.School);

Day 5 — 继承 / 接口 / 多态 / 泛型

🎯 目标：理解「面向接口编程」，这是上位机驱动层设计的核心思想。

📌 今天用到的技术从哪来 | 写法 | 来源 | 说明 | |---|---|---| | interface / : 父类 / : 接口 | 🟦语法 | 接口与继承关键字 | | void Connect() | 🟦语法 | 方法签名 | | 多态（父类/接口引用子类对象） | 🟦语法 | OOP 特性 | | where T : IComparable<T> | 🟦语法 | 泛型约束 | | T Max<T>(...) 泛型方法 | 🟦语法 | 类比 TS Array<T> |

📖 通俗讲解 - 继承：class 卡车 : 汽车 表示卡车「是一种」汽车，复用汽车的能力。 - 接口（interface）：像「插座标准」。不管什么厂家的设备，只要插口（接口）一样，上位机就能连。上位机里常用 IDevice 接口统一不同 PLC/仪表。 - 泛型：List<T> 的 T 是「占位类型」，对照 TS 的 Array<T> / List<T>。

💡 关键代码

interface IDevice { void Connect(); }      // 统一标准
class ModbusDevice : IDevice { public void Connect() => Console.WriteLine("连Modbus"); }
class PlcDevice : IDevice { public void Connect() => Console.WriteLine("连PLC"); }

void Use(IDevice d) => d.Connect();         // 多态：不管哪种设备都能用
Use(new ModbusDevice());
Use(new PlcDevice());

// 泛型
T Max<T>(T a, T b) where T : IComparable<T> => a.CompareTo(b) > 0 ? a : b;

✏️ 练习 1. 定义接口 IAnimal 含 Speak()，让 Dog 和 Cat 实现。 2. 写一个方法接收 IAnimal 并调用 Speak()（多态）。 3. 用泛型写 Swap<T>(ref T a, ref T b) 交换两个变量。

✅ 答案

interface IAnimal { void Speak(); }
class Dog : IAnimal { public void Speak() => Console.WriteLine("汪"); }
class Cat : IAnimal { public void Speak() => Console.WriteLine("喵"); }
void Speak(IAnimal a) => a.Speak();
Speak(new Dog()); Speak(new Cat());

void Swap<T>(ref T a, ref T b) { T t = a; a = b; b = t; }

Day 6 — 委托 / 事件 / Lambda

🎯 目标：理解「把方法当变量传」和「事件驱动」，对照 JS 的回调和 addEventListener。

📌 今天用到的技术从哪来 | 写法 | 来源 | 对照 | |---|---|---| | delegate void LogHandler(...) | 🟦语法 | "方法的类型"，类比函数类型 | | event Action<T>? | 🟦语法 | 事件，类比 addEventListener | | LogHandler log = (m) => ... | 🟦语法 | 委托赋 Lambda | | += 订阅事件 | 🟦语法 | 类比 addEventListener | | ?.Invoke(...) 安全调用 | 🟦语法 | 空值判断后调用（类比 ?.） | | Action<T> | 🟩.NET 类库 | 内置委托类型（BCL，类比 JS 回调类型） |

📖 通俗讲解 - 委托（delegate）：可以理解为「方法的类型」。就像 int 是数字的类型，委托是「函数」的类型。 - 事件（event）：和前端 button.addEventListener('click', fn) 一模一样 —— 设备「数据到了」就通知订阅者。 - Lambda：x => x + 1 就是 JS 的箭头函数，前面 Day 3 已经用过。

💡 关键代码

// 委托：方法的类型
delegate void LogHandler(string msg);
LogHandler log = (m) => Console.WriteLine($"[日志]{m}");
log("系统启动");

// 事件：像 addEventListener
class Sensor
{
    public event Action<double>? DataReceived;
    public void Read() => DataReceived?.Invoke(36.5); // 通知订阅者
}
var s = new Sensor();
s.DataReceived += (v) => Console.WriteLine($"收到温度：{v}");
s.Read();

✏️ 练习 1. 定义一个 event Action<string> MessageArrived，订阅后打印消息。 2. 用 Lambda 订阅该事件，触发时输出「收到：XXX」。 3. （挑战）做一个「按钮点击计数器」：每次触发事件计数 +1。

✅ 答案

class Messenger
{
    public event Action<string>? MessageArrived;
    public void Send(string m) => MessageArrived?.Invoke(m);
}
var m = new Messenger();
m.MessageArrived += (msg) => Console.WriteLine($"收到：{msg}");
m.Send("Hello");

// 挑战
int count = 0;
m.MessageArrived += (_) => { count++; Console.WriteLine($"第{count}次"); };
