# DAQ Monitor · 学习总纲（M0–M14）

> **北极星目标**：学完 = 上位机 **13~15K** 水平 + 简历上能放得出手的企业级项目「DAQ Monitor 工业数据采集监控系统」。
> **路线**：项目驱动 —— 先有项目骨架，每个模块 = 给简历项目加一种企业级能力，学完即落地。

## 13~15K 简历项目「达标清单」
1. **多设备接入**：串口 / Modbus / PLC 至少两种（M1–M3）
2. **并发采集**：后台线程 + 队列缓冲 + UI 刷新，无卡顿、无内存泄漏（M0 Day7）
3. **实时可视化**：动态曲线 / 仪表盘（M5）
4. **数据持久化**：历史库 + 查询 / 导出（M4）
5. **报警**：阈值规则 + 通知 + 日志（M6）
6. **工程素养**：分层架构 / 面向接口 / MVVM / 配置化 / 异常处理 / 单测 / DI / 统一采集 / 生产容错 / 能打包演示（M0, M8, M9）
7. **加分**：OPC UA / MQTT 上云（M7）
8. **多协议接入**：TCP 私有协议 + 串口 + Modbus + 多品牌 PLC（M1/M2/M3/M11/M13）
9. **工程量标定**：原始值 → 真实物理量（M12）
10. **企业数据库**：SQL Server / MySQL 持久化（M12）
11. **交付素养**：配置化 / 自动更新 / 文档能力（M8 / 文档能力附录）

## 技术来源 3 色标注（全程）
- 🟦 **C# 语法**：语言自带，装好 .NET 就有，**不装包**
- 🟩 **.NET 类库 BCL**：微软标准库，`using` 即用，**默认不装包**（少数如 `System.IO.Ports` 需 `dotnet add package` 但仍是官方）
- 🟧 **第三方 NuGet**：必须 `dotnet add package 包名`
- 口诀：**语法天生物 · BCL 随 .NET · 第三方要装包**

## 怎么用（统一入口）
> **📌 一个入口搞定**：直接打开 **`site/index.html`**（DAQ Monitor 学习站）——首页是模块卡片，点卡片进对应模块独立学习页，左侧目录 / 顶部技术来源图例 / 每节打卡 / 上一篇下一篇 / 返回首页，不用再一个文件一个文件找。改完 Markdown 跑 `python build_site.py` 重建整站（说明见 `site/README.md`）。

1. **零基础先读** `实操入门_从零搭建企业级工程.md`：学会命名、用命令行建工程、跑 build/run/test——这是"从最简单的做起"。也可直接点首页「实操入门」卡片。
2. 进首页点模块卡片（M0→M14 顺序学）；想一页通读也可打开旧版 `学习总纲_全模块深度版.html`（或各 `Mx_*.html`）。
3. 每天：看讲解 → 按 `练习阶梯_从简单到企业级.md` 的 L1→L2→L3 递进做练习（先自己写，再对照 ✅ 答案）→ 做 🏗️ 项目任务 → 勾 ✅ 打卡。
4. 卡住就说「讲 Day N 的 XX」或「Day N 练习答案」，我展开讲。
5. 每完成一个模块，把 DAQMonitor 对应代码提交 Git，作品集逐步成形。
