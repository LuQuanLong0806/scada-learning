30-45 天作战路线 · 转行冲刺版(代码练习融入日常版)

北极星:30-45 天后(看你节奏,赶进度可压到 30 天,内容多可放宽到 45 天),简历上有一个你自己一行行手敲出来的「DAQ Monitor 工业数据采集监控系统」,投 13-15K 上位机岗。 核心策略:讲义(理论)+ 练习(代码肌肉)+ 手敲进项目(实践) 三位一体。每天 = 看讲义 → 做练习 → 把今天学的写进你的 DAQMonitor。学完 = 项目手敲一遍。 节奏建议:每天 5-6 小时(深度学习 2h + 手敲项目 2h + 代码肌肉 1h + 打卡复盘 0.5h)。周末加量。如果某周内容偏重(如 Week 1 通讯基础 + Week 3 上云),允许延长 3-5 天,不要为了赶进度跳过手敲。 前置:你是中高级前端,所以 M0 大部分速过(只精读"C# 陷阱专项")。 节奏调整原则:学会为标准,不是看时间为标准。每个 Day 的"打卡"全部 ✅ 才能进下一天;某天没空就休息,不要"半懂就过"。

陷阱描述

你拿到的:
  ├── DAQMonitor/            ← 完整工业级代码(85 测试绿)— 这是「参考答案」
  ├── 22 个讲义.md            ← 解释每个模块
  └── 代码肌肉手册             ← 白板题库

陷阱:
  读 DAQMonitor 代码点头"懂了" → 关掉参考 → 一字写不出
  面试官:"现场写 ModbusDevice" → 你卡死

5 年前端理解能力极强,但理解 ≠ 默写。面试是默写场景,不是阅读理解。

0. 开始之前(必读 30 分钟)

心态校准

  • 前端 vs 上位机的本质差:前端是「快速迭代+用户体验」,上位机是「7×24 稳定+协议正确+现场排错」。慢就是快,稳就是好。
  • 三大致命坑(前端背景必踩):① struct 值类型拷贝 ② 字节序/CRC 位运算 ③ async void 吞异常。Day 1 必读 C#_陷阱_前端转上位机必看_深度版.md。

代码肌肉训练的纪律(🔑 转行核心)

  • 白板:不准用 IDE 自动补全,VS Code 关闭 IntelliSense 或用记事本写
  • 限时:超时也算完成,但标"未达标",二刷时降低时间
  • 错题本:错的题写到 错题本.md,每天复习
  • 可讲:写完必须能口头讲清思路(模拟面试官追问)
  • 二刷:错题 3 天后二刷,7 天后三刷,直到不假思索写出

环境清单

  • .NET 8 SDK + Visual Studio 2022(勾「.NET 桌面开发」)
  • VS Code(写 md / Python 脚本 / 白板刷题)
  • Git + GitHub(每天 commit)
  • 可选:VMware + Ubuntu(后续 OPC UA/MQTT broker 用)

Day 0.5(周日晚上,30 分钟)· 建立 DAQMonitor-mine 空骨架(必做)

为什么加这一步:你看 实操入门 是"读懂",但面试官问"你这项目怎么建的",你能脱口而出 dotnet new sln + 3 个 csproj + reference 才算你的。只花 30 分钟,在你自己的工作目录建一个空骨架——这就是你接下来 30 天每天往里加代码的项目。

动作清单(全部命令行,不用 VS):

# 1. 在你的工作目录(不在 DAQMonitor 参考版内)新建空项目
mkdir DAQMonitor-mine && cd DAQMonitor-mine
git init

# 2. 建解决方案 + 3 个工程(对照参考版 DAQMonitor/src/ 的结构)
dotnet new sln -n DaqMonitor
dotnet new classlib -o src/DaqMonitor.Core -n DaqMonitor.Core
dotnet new wpf      -o src/DaqMonitor.UI   -n DaqMonitor.UI
dotnet new xunit    -o src/DaqMonitor.Tests -n DaqMonitor.Tests

# 3. 工程引用关系(UI/Tests 都用 Core)
dotnet sln add src/DaqMonitor.Core/DaqMonitor.Core.csproj
dotnet sln add src/DaqMonitor.UI/DaqMonitor.UI.csproj
dotnet sln add src/DaqMonitor.Tests/DaqMonitor.Tests.csproj
dotnet add src/DaqMonitor.UI/DaqMonitor.UI.csproj reference src/DaqMonitor.Core/DaqMonitor.Core.csproj
dotnet add src/DaqMonitor.Tests/DaqMonitor.Tests.csproj reference src/DaqMonitor.Core/DaqMonitor.Core.csproj

# 4. 验证
dotnet build           # 必须 0 错
dotnet test            # xUnit 默认 1 个测试通过
dotnet run --project src/DaqMonitor.UI   # WPF 空窗口能开

# 5. 推到 GitHub(你的私人仓库,简历用)
git add -A
git commit -m "chore: init DAQMonitor-mine skeleton (Day 0.5)"
git remote add origin git@github.com:你的用户名/DAQMonitor-mine.git
git push -u origin main

别删!这是你接下来 30 天的"主战场",每天 commit 都进这里。
