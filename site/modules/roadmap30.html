30-45 天作战路线 · 转行冲刺版(代码练习融入日常版)

北极星:30-45 天后(看你节奏,赶进度可压到 30 天,内容多可放宽到 45 天),简历上有一个你自己一行行手敲出来的「DAQ Monitor 工业数据采集监控系统」,投 13-15K 上位机岗。 核心策略:讲义(理论)+ 练习(代码肌肉)+ 手敲进项目(实践) 三位一体。每天 = 看讲义 → 做练习 → 把今天学的写进你的 DAQMonitor。学完 = 项目手敲一遍。 节奏建议:每天 5-6 小时(深度学习 2h + 手敲项目 2h + 代码肌肉 1h + 打卡复盘 0.5h)。周末加量。如果某周内容偏重(如 Week 1 通讯基础 + Week 3 上云),允许延长 3-5 天,不要为了赶进度跳过手敲。 前置:你是中高级前端,所以 M0 大部分速过(只精读"C# 陷阱专项")。 节奏调整原则:学会为标准,不是看时间为标准。每个 Day 的"打卡"全部 ✅ 才能进下一天;某天没空就休息,不要"半懂就过"。

📂 关于 src/ 目录(新手必看)

❓ 常见卡死

报错 原因 解法
dotnet new wpf 失败 你在 Mac/Linux 上 WPF 只能 Windows 跑,改用 WinForms 或换 Windows 机器
dotnet test 报 "No test found" xUnit 模板版本差异 跑 dotnet new xunit -o src/DaqMonitor.Tests 重建测试工程
dotnet run 报找不到 MainWindow WPF 模板没装 装 .NET Desktop Runtime + 桌面开发 workload
git push 报 Permission denied SSH key 没配 看 https://docs.github.com/ssh 配 key,或改用 HTTPS
dotnet build 报 NETSDK109 SDK 版本太低 装 .NET 8 SDK 或更高

⚠️ EF Core 4 大必考点(15K 面试官会追问,讲义缺口,在此补): 1. 为什么 DbContext 不能单例:变更追踪字典(ChangeTracker)非线程安全,同一实体被多线程同时修改会脏读;SaveChanges 是串行的,多个线程并发调会报 "A second operation was started on the same context instance" 异常。正确做法:AddDbContextFactory(工厂,每次 CreateDbContext() 拿短命实例)或 AddDbContext(Scoped)(每个 HTTP 请求/工作单元一个) 2. 学习(2h):PLCopen 标准 + 轴状态机(讲义缺口补)

为什么补这一节:M19 讲义没讲运控,DAQMonitor 项目里直接实现了 IAxisController 等代码但没讲原理,这是讲义缺口。先补理论再手敲,避免"看代码点头、关掉写不出"。

  • PLCopen Motion(IEC 61131-3 标准):MC_MoveAbsolute / MC_MoveRelative / MC_Home / MC_Stop 4 大动作 — 工业通用语言,固高/雷赛/正运动/Beckhoff 都对齐这套命名,面试讲法标准化
  • 轴状态机(5 态): Disabled ──Enable──> Idle ──Move/Jog──> Moving ──完成──> Idle Idle ──Home───> Homing ──完成──> Idle 任意态 ──E-Stop──> Idle(立即停,但工业现场规范要求 E-Stop 后需操作员确认 → Reset 才能再 Move,本模拟器简化版直接回 Idle,真机/严格规范需加 Stopping 中间态) 任意态 ──超限/超速/驱动故障──> Alarm(锁死,需人工 Reset)

    注:严格 PLCopen 规范的 E-Stop 进 Aborting/Stopping 中间态、完成减速后才回 Idle 或 ErrorStop(若同时驱动故障);学习版状态机做简化,但面试被追问时要会答:"严格规范 E-Stop 不是瞬时回 Idle,要走 Stopping 减速曲线;真机版我会加 Stopping/ErrorStop 中间态,本模拟器为教学简化为直接回 Idle"

  • 软限位 vs 硬限位:软限位 = 软件检查 MinPosition/MaxPosition 拦截;硬限位 = 物理限位开关 + 继电器急停电路(独立于软件,软件挂了一样能停)
  • 回零为什么必须:编码器只能记相对位移,机械装好后真实位置未知,必须慢速移动碰到回零开关 → 反向脱离一小段 → 记录 0 点。未回零时绝对定位无意义
  • E-Stop vs Stop:E-Stop 立即切断伺服输出(可能丢位置,但避免碰撞);Stop 走减速曲线(平稳,不丢位置)
  • CountsPerUnit:脉冲 ↔ 用户单位转换系数(如 10000 脉冲/mm),真卡 API 用脉冲,业务用 mm,中间靠这个系数
