📴 内网学习完全手册 · 量身定做版

写给谁:白天在公司内网、无外网、想完整完成「学习+练习+理解」闭环的你。 核心结论先行:这套资料的讲义全部自包含(代码经沙盒验证、无 CDN 依赖),项目自带零硬件测试(回环/模拟/进程内从站)——内网不是降级环境,而是恰好匹配这套资料设计哲学的环境。缺的只是 NuGet 包和 SDK,本文教你一次备齐。

〇、离线包使用时间线:什么时候用、怎么用(先看这节)

一句话定义:离线学习包 = 家里电脑的一次「快照 + 预装弹药」。在家学习永远直接用 scada-learning 仓库,不碰离线包;离线包只在两个时刻登场——带去内网之前(准备)、在内网机器上(使用)。

生命周期三阶段

阶段 什么时候做 做什么 用时
① 首次准备 开始内网学习前,在家做一次 跑 在家准备离线包.ps1(拉齐 NuGet)+ 可选下载 SDK zip → 整个文件夹拷进 U 盘 15-30 分钟
② 内网初始化 内网机器第一天 U 盘拷到内网机 →(🥇档)解压 SDK + 放 NuGet.config → 验证 restore/test 全绿 10 分钟
③ 日常循环 每个工作日 白天:内网用 site 学习 + 改代码;晚上:回家 3 分钟同步(代码合并 + 问题清单批改) 每晚 3 分钟

三条铁律(防坑)

  1. 家 = 仓库,内网 = 离线包,不要交叉改:家里改代码永远改 scada-learning\DAQMonitor;内网改的是包里的副本——回家用 git/文件拷贝合并,别两边各自长出没同步的版本。
  2. site 以家为准,里程碑后重拷:内网完成教练计划某课 / 家里站点有更新 → 回家 python build_site.py → 重拷 site\ 进 U 盘 → 内网覆盖。
  3. 离线包不是备份:它不含 git 历史。内网写的代码怕丢,当天就拷回 U 盘(或推到内网 git)。

决策树:「我现在想做 X → 去哪」

我想看讲义/背面试题   → site\index.html
我想跑项目看数据流    → DAQMonitor\...\DaqMonitor.UI.exe(或 VS F5)
我想改代码/跑测试     → 🥇档:SDK + NuGet.config + dotnet build/test
我卡住了            → 术语表 → 知识点弹窗 → 记白天问题清单(晚上问)
我要下班了          → 拷当天改动 + 问题清单 → 回家合并 + 问问题
家里站点更新了       → 重拷 site\ 到 U 盘 → 内网覆盖

四、在家准备流程(一次性,15 分钟)

  1. 在家电脑跑 在家准备离线包.ps1(U 盘/移动硬盘接到家机):它会 ①还原两个工程拉准 A 表所有包 → ②建临时工程把 B 表全部包拉进缓存 → ③把 NuGet 缓存(~1.5GB)拷进离线学习包;
  2. 手动下载(可选):.NET SDK 便携 zip(MSDN 官网)→ 放进 离线学习包\tools\;
  3. 整个 离线学习包 文件夹拷进 U 盘 → 完成。

五、内网机器初始化(第一次,10 分钟)

# 1️⃣ 把 U 盘内容拷到内网机任意盘,如 D:\offline\
# 2️⃣ (🥇档)解压 SDK zip 到 D:\offline\sdk,然后用它跑命令:
D:\offline\sdk\dotnet.exe --info

# 3️⃣ 关键一步:给工程配"只走本地"的包源
#    包根目录已备好 NuGet.config.template(相对路径版):
#    把它拷进 DAQMonitor 文件夹,改名为 NuGet.config 即可(保留离线学习包目录结构时零修改)。
#    目录结构不同才需要改里面的 value 路径。

# 4️⃣ 验证:断网状态下
D:\offline\sdk\dotnet.exe restore DaqMonitor.sln     # 应全部成功
D:\offline\sdk\dotnet.exe build                      # 0 错误
D:\offline\sdk\dotnet.exe test                       # 85/85 绿

NuGet.config 的 <clear/> 是灵魂:清空 nuget.org,restore/add 全部只认本地文件夹——这就是"内网搞到包"的完整答案。以后 dotnet add package FluentModbus 也会从本地解析。 ✅ 已在 2026-08-24 金标准验证:空全局缓存 + 仅离线源,net8.0 解决方案 restore/构建全部成功(163 个包实际从离线文件夹解析),全部包按 .NET 8 兼容拉取。

六、内网每日学习 SOP(对应教练计划三档吃法)

① 打开 site\index.html → 教练计划 → 看今天该学哪课
② 🅑读档:VS/vscode 打开 DAQMonitor → 断点 → F5 走数据流 → 合上文档自己讲一遍(出声)
③ 🅐敲码:调库版/改功能 → dotnet build/test 全绿 → git commit(内网仓库或本地提交,回家 push)
④ 卡词 → 术语表;卡概念 → 📖 知识点弹窗;卡壳超 30 分钟 → 记「白天问题清单.txt」→ 降级🅒跳过
⑤ 白纸手写 1 道代码肌肉题(手册有答案,写完自己对)
⑥ 下班拷贝:当天改的代码 + 问题清单.txt 回家

没有教练的自助三层:术语表(60 词)→ KPOINTS 弹窗(30+ 概念)→ 问题清单(晚上批改)。90% 的卡点在前两层就能解——讲义本来就把"为什么"写在正文里,内网读和联网读没有区别。

七、练习在内网怎么做(零妥协方案)

练习类型 内网做法 完整度
讲义 L1/L2/L3 练习 照做(纯代码,无网依赖) 100%
代码肌肉白板题 白纸写 → 手册对答案 → 错题记清单 100%

八、回家同步(3 分钟仪式)

  1. git bundle 或直接拷文件:内网改动 → 家里仓库 commit;
  2. 问题清单 → 逐条问 Cline → 高频问题升级成站点新页;
  3. site 有更新 → 重拷 site\ 目录进 U 盘 → 明天内网就是新版。

九、合规提醒

带个人学习资料入内网前,确认公司制度允许(自学材料一般无碍;涉密内网严禁私带存储介质,先问 IT/主管一句话,别踩红线)。
