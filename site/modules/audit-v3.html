⚠️ P2 留给后续补(讲义级缺口,改 M2/M3/M4 工作量大)

1. M2 Modbus 深度补 3 点(15K 必考)

  • CRC16 反射多项式:讲算法时只给 0xA001,没说为什么是 0xA001 而不是 0x8005。补一句:"Modbus 用 LSB-first 位移实现,采用反射多项式,0x8005 反转后 = 0xA001"。面试官追问"为啥反转"才答得上来
  • TCP vs RTU 并发性差异:讲 TCP/RTU 差异时只说"去 CRC + MBAP 头",漏了并发性:TCP 走 6 字节 MBAP 头含事务元 ID,支持并发请求(多请求同时发,响应按 ID 匹配);RTU 单总线串行,必须排队轮询。15K 必问
  • TCP 粘包解法缺第三种:M11 只讲"长度前缀 / 分隔符",漏了"固定长度法"(每帧定长)。面试常追问"还有别的吗"

2. M3 PLC 深度补 3 点(15K 半导体设备岗必问)

  • Snap7 vs S7.Net 对比:M3 只用 S7.Net,完全没提 Snap7。补:Snap7 是 C++ 原生绑定,性能更高 / 支持 300/400/1200/1500 全系 / 国内厂商更常用;S7.Net 纯托管 C#,仅 200/1200/1500
  • 1200 vs 1500 通信差异:1500 PUT/GET 默认开启、1200 默认关闭;1500 有 Profinet IRT、1200 只有 RT;1500 DB 块默认优化、1200 早期版本绝对寻址
  • 优化块访问机制:M3 一句"勾掉优化访问"带过,没讲机制:符号寻址 vs 绝对偏移、TIA 内部按符号哈希存储、S7.Net v3 的 ReadClass 才能读优化块

3. M4 EF Core 注册方式自相矛盾(技术正确性)

  • L72 推荐 AddDbContextFactory,L113 注释又写"AppDbContext(Scoped 生命周期)"。两种注册混着说会让面试官问"你到底用哪种"懵
  • 修复:统一表述 — 高并发采集用 Factory、Web 请求用 Scoped;讲义改一处即可

4. M9 / 逐字稿 多线程 4 选 1 缺失(15K 必考)

  • Monitor vs Mutex vs SemaphoreSlim 怎么选:Monitor 进程内轻量、Mutex 跨进程、SemaphoreSlim 异步资源限流 — 讲义没对比
  • Channel vs BlockingCollection:Channel 异步原生 awaitable、BlockingCollection 同步阻塞消费线程,Channel 是 .NET Core 后续首选 — 讲义没对比
  • SynchronizationContext 下 await 线程切换:WPF ConfigureAwait(true) 回 UI 线程、false 不回 — C# 陷阱提了 ConfigureAwait 但没讲 SC
  • 修复:在 面试问答_逐字稿_30题.md Q4-Q6 区域补 4 题(每题 200 字)

5. 运动控制概念外延(Day 27.5)

Day 27.5 只讲 PLCopen 抽象,没讲插补/伺服步进/EtherCAT。这不是 bug 是设计取舍 — 只学 1 天不可能全懂,靠"诚实回答模板"覆盖(已在 Day 27.5 简历话术一节加诚实降级 + 面试被追问的回避话术)。如果想再深一层,补: - 直线插补要 2 轴 + 速度同步;圆弧插补要圆心 + 半径 + 起止角 + 进给速度 - 伺服闭环(编码器反馈,不丢步) vs 步进开环(易失步,成本 1/3) - EtherCAT 周期 100μs~1ms vs 脉冲+方向最高 500kHz(无实时反馈)
