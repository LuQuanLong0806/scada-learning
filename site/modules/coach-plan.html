🧭 学习模式裁定:三档吃法(开工前先读这节)

回答"要不要敲 / 要不要背":整本照敲是给真初学者的(他们是边敲边学语法),你是"领域新手 + 6 年工程老手",不需要;纯背诵会在面试第二问穿帮("Channel 和 BlockingQueue 区别?"→ 只有真断点过的人才接得住)。 正确姿势:每个组件按 🅐敲 / 🅑读 / 🅒扫 三档分流,时间花在刀刃上。

两项目分流表(实际进度:R1+R2 已敲完):

内容 档位 理由
R3 协议解析(CRC/帧) 🅒 概念已由 ByteOrderLab + 知识点弹窗覆盖,代码不敲
R4 调库版 ModbusDevice + 测试 🅐 ~100 行业务层(连接/轮询/重连全是你写),JD 对口,一晚拥有
R4 TcpDevice 心跳重连 🅑 面试常问,断点走一遍指数退避
R5 管道 + 报警 🅑 全项目心脏(80+53 行),必须能讲"为什么批量/为什么回滞"
R6 双写 / R7 DI 组合根 🅑 断点看写泵落库;DI 你有底子,快
R8 主界面 🅐 前端主场,顺手加简历锚点功能
MC1 仿真卡 / MC3 界面 🅑 并发令牌 + 跨线程刷 UI = 面试多线程题,断点看
MC2 / MC4 / MC5 🅒 tickMs 快进思路 / STA 三句话 / 插补一句话带过
MC6 轨迹图 🅐 canvas 主场,2 小时,简历亮点("前端能力可视化证据")

背诵的正确姿势:「🎤 面试一句话」要背,但它是理解的输出,不是理解的替代——读档懂了 → 合上讲一遍 → 再背压缩版 → 让 Cline 追问模拟第二问。

30 分钟规则:读档卡壳超 30 分钟 → 查术语表 → 问 Cline → 或降级 🅒 标记回来补。不恋战,一周后要投简历。

完工自检(4 问):① 项目能跑? ② 数据流能白板画? ③ 术语表第 5 节的 8 个新概念能各讲 1 分钟? ④ 至少亲手改过 1 处?——四问全 ✅ = 项目吃透,去投简历。
