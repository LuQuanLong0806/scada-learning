一、通讯类(最大的一座"假山")

工业黑话 人话(一句话) 你的前端等价物
回环 Loopback 字节写进去,原样"假装是设备回的"弹回来 msw / axios-mock-adapter 拦截请求返回假响应
模拟通道 SimulatedChannel 接口的假实现,专供测试 mock 实现 / fake service
主站 Master 主动发问的一方(=你的上位机) 发请求的浏览器/client
从站 Slave 被问话的设备端(一问一答) 被调用的 server
进程内从站 测试里在内存起一个假设备服务器 Vitest mock fetch / in-memory server

订阅推送 设备有数据主动上报 WebSocket / SSE 推送
粘包 两条消息的字节连在一起到达 WebSocket 攒 buffer 切消息
半包 一条消息只到了一半 流式 chunk 读取,没攒够不处理
拆帧/组帧 从字节流切出一条完整消息 / 拼出一条消息 message framing / 解析 buffer 协议
帧 Frame 一条消息的固定格式(头+长度+数据+校验) 自定义消息协议 schema
帧头 AA55 每条消息开头的暗号字节 消息 magic number / 协议标识

静默判掉线 N 秒没消息就认为断了 WebSocket onclose / timeout

抖动 jitter 退避时间加随机量,防同时重试 同左,业界通用套路
重同步 resync 流错位后丢垃圾字节重新找帧头 流解析器 reset / 重新对齐
RTU / TCP Modbus 的串口版 / 网口版 同一 API 的两种 transport
功能码 "读寄存器/写线圈"等操作编号 REST 的 method+path

五、真正的新概念清单(前端完全没有,需要真学)

只有这些是真·新知识,总共 8 个,每个都不难:

  1. CRC —— 防伪指纹,15 行代码,记住"低字节在前"即可
  2. 字节序两层结构 —— 寄存器内大端 + 跨寄存器字序(ByteOrderLab 已亲手玩过)
  3. 主从问答协议 —— 一问一答的时序(比 REST 还简单,没有回调)
  4. 报警回滞 —— 施密特触发器思想(理解后 1 分钟讲清)
  5. PLC / DB 块 —— 设备侧的数据存储概念(知道是什么即可)
  6. 现场抗干扰 —— 接地/屏蔽/隔离,硬件话题(面试口头了解)
  7. RS232/485/4-20mA —— 物理层硬件知识(科普级了解)
  8. 使能/软限位/急停 —— 运控安全语义(概念简单,行业约定)

六、使用协议

  1. 读任何文档卡词 → 先查本表
