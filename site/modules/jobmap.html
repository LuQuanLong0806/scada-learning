3. 遗漏清单（这是你最在意的"不能遗漏"）

3.1 本次审计新发现的真实遗漏（之前调研没覆盖）

  1. ❌ Git 版本管理 + 敏捷开发流程 —— 初级 JD 普遍硬性要求，现有文档 0 覆盖。这是"能不能进团队干活"的门槛，不是可选项。
  2. ❌ 硬件调试工具（示波器 / 逻辑分析仪 / 协议分析仪 / 串口助手） —— 苏州初级 JD 原句"熟悉示波器或逻辑分析仪基本使用"。我们只有"串口助手"提了一句，没系统讲怎么用这些工具看信号、定位联调问题。
  3. ❌ CAN 总线 —— 天津初级 JD 原句把 CAN 和 Modbus/TCP/IP/串口并列点名。工业现场（尤其汽车/军工/半导体设备）极常见，现有文档完全没提。
  4. ❌ USB / HID 通信 —— 苏州初级 JD 原句"USB/串口/蓝牙"。仪器类设备（流量计、泵、扫码枪）大量走 USB-HID，现有文档没覆盖。
  5. ❌ WebApi / REST / 前后端分离 —— 上海初级 JD 原句 + 拓斯达 JD(WebApi)。部分上位机要暴露 HTTP 接口给 MES/其他系统，现有只有 MQTT/OPC UA。
  6. ❌ Prism 框架 —— 之前调研已标为 gap，至今未补。工业上位机"企业标准"MVVM 框架，比自研 Bootstrapper 更规范。
  7. ❌ WCF —— 个别 JD 点名（上海初级），niche，但既然 JD 写了就记上。

3.2 之前已发现、本次确认仍偏薄/遗漏

  1. ⚠️ 算法/数据处理：JD 点名"数据处理算法/图形算法"，现有只讲 LINQ，没系统讲滤波(滑动平均/中值)、标定点(线性/查表)、曲线拟合——这些是工程量转换的底层。
  2. ⚠️ 多品牌 PLC + HslCommunication：M13 仅 3.4KB，太薄。
  3. ⚠️ WPF 自定义控件：M14 只做了 WinForm 自绘，WPF 侧（你项目用的正是 WPF）反而没专门练。
  4. ⚠️ 文档能力练习量：模板有，但缺"动手写一份真实协议文档/接口文档"的练习。

5. 一句话结论

现有 M0–M14 已经扎实覆盖了初中级主干必会项（C#→WPF→串口→Modbus→PLC→数据库→并发→上云→工程素养），且工程素养超出一般 JD。但本次对照真实初中级 JD 审计，新发现 6 个真实遗漏：Git/敏捷、硬件调试工具、CAN、USB-HID、WebApi/REST、Prism——其中前 4 个是初级岗硬要求，必须补。

补完 M15(工程协作与联调) + M16(工业总线 CAN/USB) + M17(框架级 Prism/WebApi) 并把 M12/M14/文档附录补厚后，学完 = 资深中级达标、项目可交付企业。运动控制卡/机器视觉属行业加分，按目标岗位（你做的是 DAQ 监控类）暂不强制。
