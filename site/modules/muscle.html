Part A · 前端 → C# 翻译题(20 道)

目标:1 周内消除 C# 语法陌生感,把前端经验直接迁移过来。 节奏:每天 4 道,5 天刷完。每道 5 分钟,翻译完对照答案找差异。

A1. Promise → Task

// JS
function fetchUser(id) {
  return fetch(`/api/users/${id}`).then(r => r.json());
}
const user = await fetchUser(1);

翻译成 C#:

// C#
async Task<User> FetchUserAsync(int id)
{
    var resp = await _httpClient.GetAsync($"/api/users/{id}");
    return await resp.Content.ReadFromJsonAsync<User>();
}
var user = await FetchUserAsync(1);

关键差异: - Promise<T> → Task<T> - then(cb) → await(语言级,更直观) - 命名约定:Async 后缀(C# 强约定) - 配置 await:ConfigureAwait(false)(库代码必加,UI 代码不用)

A2. Promise.all → Task.WhenAll

const [a, b, c] = await Promise.all([fa(), fb(), fc()]);

var tasks = new[] { FaAsync(), FbAsync(), FcAsync() };
await Task.WhenAll(tasks);
// 注意:Task.WhenAll 返回 Task,不带结果数组,要单独拿
var a = tasks[0].Result;   // 这里 .Result 安全,因为已 await WhenAll

关键差异: - Promise.all 返回数组,Task.WhenAll 不返回(要单独 .Result 拿) - 异常处理:Promise.all 抛第一个,Task.WhenAll 抛 AggregateException(所有异常聚合)

A3. Promise.race → Task.WhenAny

const fast = await Promise.race([slowAsync(), timeout(5000)]);

using var cts = new CancellationTokenSource(5000);
var result = await SlowAsync(cts.Token);   // 超时自动抛 TaskCanceledException

关键差异: - C# 不用 WhenAny 实现超时,用 CancellationTokenSource(5000) 更优雅 - WhenAny 用得少,知道有这东西就行

A4. Array.map → LINQ Select

const squares = [1,2,3].map(x => x*x);

var squares = new[] { 1, 2, 3 }.Select(x => x * x).ToArray();

关键差异: - LINQ 默认 lazy(返回 IEnumerable),.ToArray() / .ToList() 才求值 - 前端 .map 立即求值,C# 延迟求值

A5. Array.filter / reduce → LINQ Where / Aggregate

const sum = [1,2,3].filter(x => x > 1).reduce((a, b) => a + b, 0);

var sum = new[] { 1, 2, 3 }.Where(x => x > 1).Aggregate(0, (a, b) => a + b);
// 或更简单
var sum = new[] { 1, 2, 3 }.Where(x => x > 1).Sum();

A6. addEventListener → event +=

btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);   // 必须同一引用

btn.Click += Handler;

关键差异: - C# event 类型安全(签名必须匹配 EventHandler) - Lambda 不能 -=(没引用),必须具名方法或存字段

A7. useState → INotifyPropertyChanged

const [count, setCount] = useState(0);

public int Count
{

// 使用方

B1. 手写 Modbus CRC16(⏱️ 5 分钟)

题目:写一个 static ushort ComputeCrc(byte[] data),实现 Modbus CRC16。

目标答案:

public static ushort ComputeCrc(byte[] data)
{
    ushort crc = 0xFFFF;
    foreach (var b in data)
    {
        crc ^= b;
        for (int i = 0; i < 8; i++)
        {
            if ((crc & 0x0001) != 0)
            {
                crc >>= 1;
                crc ^= 0xA001;
            }
            else crc >>= 1;
        }
    }
    return crc;
}

// 使用:验证 01 03 00 00 00 02 的 CRC = 0xC40B → C4 0B(低字节在前)

易错点:① 初值 0xFFFF 不是 0;② 多项式 0xA001(0x8005 位反转);③ 8 次循环不是 16 次;④ Modbus 协议 CRC 低字节在前。

面试官追问: - 为什么初值 0xFFFF?(让全 0 数据也产生非零校验) - 为什么用 0xA001 不用 0x8005?(Modbus 用反向多项式) - 怎么验证 CRC 是低字节在前还是高字节在前?(看规范 / 抓帧)

🎭 拟人段辅助记忆:见 M2_Modbus_深度版.md §CRC16 手算 「快递指纹 + 魔刷 0xA001」—— 每个字节盖一次指纹,8 轮魔刷刷出 16 位校验码。

判据:5 分钟内白板写出,不查文档,代码能跑通。

B2. 手写 System.Threading.Channel 生产者消费者(⏱️ 10 分钟)

题目:写一个采集线程(每 100ms 产生一个 int)+ 消费线程(打印平方)+ 5 秒后优雅退出。

目标答案:

using System.Threading.Channels;

var channel = Channel.CreateBounded<int>(100);
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));

var producer = Task.Run(async () =>
{
    try
    {
        while (!cts.IsCancellationRequested)
        {
            var value = Random.Shared.Next(1, 100);
            await channel.Writer.WriteAsync(value, cts.Token);
            await Task.Delay(100, cts.Token);
        }
    }
    catch (OperationCanceledException) { }
    finally { channel.Writer.Complete(); }
});

var consumer = Task.Run(async () =>
{
    await foreach (var v in channel.Reader.ReadAllAsync(cts.Token))
        Console.WriteLine($"{v}² = {v * v}");
});

await Task.WhenAll(producer, consumer);

易错点:① 没 Writer.Complete() 消费者永远等;② 没 CancellationToken 退出卡住;③ 用 async void 事件订阅异常吞(C# 陷阱讲义 陷阱 4)。

面试官追问: - 为什么用 Channel 不用 ConcurrentQueue?(异步无锁,前端类比 RxJS Subject) - 有界 vs 无界?(OOM 风险 vs 背压) - DropOldest vs Wait?(生产现场不同选择)

🎭 拟人段辅助记忆:见 M0_每日讲义_深度版.md §Day 7 「前台窗口 + 后厨传菜口」—— 后厨(采集线程)做好菜放传菜口,前台(UI 线程)按自己节奏端出去,互不卡。

B3. 手写 IDevice 实现(⏱️ 15 分钟)

题目:实现一个 SimulatedDevice,继承 DeviceBase,每 500ms 产生一个随机值,通过 DataReceived 事件触发。

目标答案:

public class SimulatedDevice : DeviceBase
{
    private readonly Random _rnd = new();
    private CancellationTokenSource? _cts;
    private Task? _loop;

    public SimulatedDevice(int id, string name) : base(id, name) { }

    public override void Connect()
    {
        if (_loop != null) return;
        State = DeviceState.Online;
        _cts = new CancellationTokenSource();
        _loop = Task.Run(async () =>
        {
            try
            {
                while (!_cts!.Token.IsCancellationRequested)
                {
                    RaiseData(Id, _rnd.NextDouble() * 100);
                    await Task.Delay(500, _cts.Token);
                }
            }
            catch (OperationCanceledException) { }
        });
    }

    public override void Disconnect()
    {
        _cts?.Cancel();
        try { _loop?.Wait(); } catch { }
        State = DeviceState.Offline;
    }

    public override double Read(int addr) => _rnd.NextDouble() * 100;
    public override void Write(int addr, double value) { /* 模拟设备无写入 */ }
}

易错点:① RaiseData 在 DeviceBase 里;② Connect() 重入保护(if (_loop != null) return);③ Disconnect 必须等 _loop 退出。

B4. 手写 Retry 指数退避(⏱️ 10 分钟)

题目:写一个 Retry.ExecuteAsync(Func<Task<T>> action, int maxRetries, int baseDelayMs) 实现指数退避 + 随机抖动。

目标答案:

public static async Task<T> ExecuteAsync<T>(Func<Task<T>> action, int maxRetries, int baseDelayMs)
{
    for (int attempt = 1; ; attempt++)
    {
        try { return await action(); }
        catch (Exception ex) when (attempt <= maxRetries)
        {
            var jitter = Random.Shared.Next(0, baseDelayMs);
            var delay = baseDelayMs * Math.Pow(2, attempt - 1) + jitter;
            await Task.Delay((int)delay);
        }
    }
}

易错点:① attempt <= maxRetries 的 when 条件(最后一次失败要抛);② 随机抖动避免 thundering herd;③ Math.Pow 返回 double 要转 int。

面试官追问:为什么指数退避要加抖动?(避免多客户端同时重试再次撞)

B5. 手写 AlarmRule 回滞(⏱️ 15 分钟)

题目:实现一个报警规则引擎,带回滞防抖(温度 > 80 报警,降到 70 以下才解除)。

目标答案:

public class AlarmRule
{
    public int PointId { get; init; }
    public double HighThreshold { get; init; }    // 80
    public double LowThreshold { get; init; }     // 70(回滞带)
    public bool IsActive { get; private set; }

    public bool Evaluate(double value)
    {
        if (!IsActive && value > HighThreshold) IsActive = true;
        else if (IsActive && value < LowThreshold) IsActive = false;
        return IsActive;
    }
}

public class AlarmEngine
{
    private readonly Dictionary<int, AlarmRule> _rules = new();
    private readonly object _gate = new();

    public event Action<int, double, DateTime>? AlarmTriggered;
    public event Action<int, DateTime>? AlarmCleared;

    public void AddRule(AlarmRule rule) { lock (_gate) _rules[rule.PointId] = rule; }

    public void OnSample(int pointId, double value)
    {
        lock (_gate)
        {
            if (!_rules.TryGetValue(pointId, out var rule)) return;
            var wasActive = rule.IsActive;
            var nowActive = rule.Evaluate(value);
            if (!wasActive && nowActive) AlarmTriggered?.Invoke(pointId, value, DateTime.Now);
            else if (wasActive && !nowActive) AlarmCleared?.Invoke(pointId, DateTime.Now);
        }
    }
}

易错点:① 锁要细(只在 Evaluate + 事件触发);② 边沿触发(只在状态变化时触发事件,不重复);③ 回滞带 = HighThreshold - LowThreshold。

面试官追问:为什么需要回滞?(防抖,温度在 79-81 之间晃,不报警每秒触发)

🎭 拟人段辅助记忆:就像空调设定 26℃ — 升到 27℃ 才启动制冷,降到 25℃ 才停机,不在 26℃ 边界反复开关机磨坏压缩机。温度报警同理,高温 +5℃ 才报,回落到阈值以下 -5℃ 才解。

B6. 手写帧解析 AA55 帧头 + 长度 + payload + CRC(⏱️ 10 分钟)

题目:实现一个 FrameParser,处理字节流粘包/半包。帧格式 AA 55 | Len | Payload | CRC_L CRC_H。提供 Feed(chunk) 喂入字节流,返回本次拆出的所有完整帧。

🎯 面试官想听到:① 半包/粘包概念;② 滚动缓冲 + 状态机思路;③ 缓冲无限增长的防御(找不到帧头就清空)。

✅ 标准答案:核心思想是滚动缓冲区 + 循环拆帧。每次 Feed 把新字节追加到 _buffer,然后 while(TryTakeFrame()) 把所有完整帧切出来返回。半包(数据不够)就 return false 等下一次;粘包(多帧粘一起)就靠 while 循环多拆几次。CRC 不过直接丢弃整帧,不让坏数据进业务。找不到 0xAA 帧头必须清空缓冲,否则内存无限涨(生产事故源)。前端类比:Node 的 Transform stream / 前端自己写 WebSocket 协议解析的 chunk 拼装。

💻 关键代码(对照 DAQMonitor/Core/Protocol/FrameParser.cs):

public class FrameParser
{
    private readonly List<byte> _buffer = new();
    private readonly bool _verifyCrc;

    public FrameParser(bool verifyCrc = false) => _verifyCrc = verifyCrc;

    public IReadOnlyList<byte[]> Feed(ReadOnlySpan<byte> chunk)
    {
        _buffer.AddRange(chunk.ToArray());
        var frames = new List<byte[]>();
        while (TryTakeFrame(out var frame))
            frames.Add(frame);
        return frames;
    }

    private bool TryTakeFrame(out byte[] frame)
    {
        frame = Array.Empty<byte>();
        int idx = _buffer.IndexOf((byte)0xAA);
        if (idx < 0) { _buffer.Clear(); return false; }          // 没帧头:清空防内存爆
        if (_buffer.Count < idx + 3) return false;               // 头+长 不齐
        if (_buffer[idx + 1] != 0x55) { _buffer.RemoveAt(idx); return false; } // 假帧头(后面不是 55)
        int len = _buffer[idx + 2];
        int total = 3 + len + 2;                                 // AA 55 LEN | payload | CRC_L CRC_H
        if (_buffer.Count < idx + total) return false;           // 半包:等更多数据

        if (_verifyCrc)
        {
            var full = _buffer.GetRange(idx, total).ToArray();
            if (!Crc16.Check(full))                             // CRC 不过:丢帧
            {
                _buffer.RemoveRange(0, idx + total);
                return false;
            }
        }
        frame = _buffer.GetRange(idx + 3, len).ToArray();
        _buffer.RemoveRange(0, idx + total);                    // 滑窗:移除已消费
        return true;
    }

    public void Reset() => _buffer.Clear();
}

⚠️ 易错点: - 缓冲无限增长:找不到 0xAA 必须清空,否则设备掉线时缓冲区涨到 OOM - CRC 校验范围:对"头 + 长 + 载荷"整体算,与 Crc16.Check(整帧) 的范围一致 - 假帧头处理:遇到 0xAA 后下一字节不是 0x55,只移除 1 字节继续扫,不要整段丢弃 - RemoveRange(0, idx + total) 不是 RemoveRange(idx, total):要把"消费过的"全部移除,包括 idx 前的垃圾字节 - List 高频小包性能差,生产用 ArrayPool<byte> + 环形缓冲(参 M11 修正版)

🎤 面试官追问: - Q: 如果对端乱发数据,没有 0xAA 怎么办? A:IndexOf 返回 -1,清空缓冲。下次正确数据来时从头开始,不会丢帧。 - Q: 1MB 的字节流里只有一个真帧,怎么避免遍历太慢? A:用 KMP 或 Boyer-Moore 找 AA 55 序列;或限制缓冲区最大长度(如 64KB),超了直接丢。 - Q: 多线程同时 Feed 怎么办? A:FrameParser 不是线程安全,串口/TCP 的接收循环是单线程读,所以没问题;若要多线程喂,外面加 lock。

💻 关键代码(对照 DAQMonitor/Core/Devices/ModbusDevice.cs):

public sealed class ModbusDevice : DeviceBase
{
    private readonly byte _slave;
    private readonly List<RegisterMap> _maps;
    private SerialPort? _port;
    private CancellationTokenSource? _cts;
    private Task? _loop;
    private readonly Dictionary<int, double> _last = new();

    public ModbusDevice(int id, string name, byte slave, IEnumerable<RegisterMap> maps,
        string portName = "COM3", int baud = 9600) : base(id, name)
    {
        _slave = slave;
        _maps = maps.ToList();
        _port = new SerialPort(portName, baud, Parity.None, 8, StopBits.One);
    }

    public override void Connect()
    {
        State = DeviceState.Connecting;
        _port!.Open();
        Start();
        State = DeviceState.Online;
    }

    public override void Disconnect()
    {
        Stop();                                  // 先停轮询,避免端口已关还在读
        if (_port?.IsOpen == true) _port.Close();
        State = DeviceState.Offline;
    }

    private void Start()
    {
        if (_loop is not null) return;           // 重入保护
        _cts = new CancellationTokenSource();
        var token = _cts.Token;
        _loop = Task.Run(async () =>
        {
            try { while (!token.IsCancellationRequested) { RealTick(); await Task.Delay(500, token); } }
            catch (OperationCanceledException) { }
        }, token);
    }

    private void Stop()
    {
        _cts?.Cancel();
        try { _loop?.Wait(500); } catch { }
        _cts?.Dispose(); _cts = null; _loop = null;
    }

    private void RealTick()
    {
        foreach (var m in _maps)
        {
            ushort count = m.Type == "float" ? (ushort)2 : (ushort)1;
            var req = ModbusFrameParser.BuildReadHoldingRequest(_slave, m.Address, count);
            _port!.Write(req, 0, req.Length);

            int waited = 0, minLen = count == 2 ? 9 : 7;
            while (_port.BytesToRead < minLen && waited < 1000) { Thread.Sleep(10); waited += 10; }
            if (_port.BytesToRead == 0) continue;

            var resp = new byte[_port.BytesToRead];
            _port.Read(resp, 0, resp.Length);
            if (ModbusFrameParser.IsExceptionResponse(resp, out _)) continue;
            if (!Crc16.Check(resp)) continue;                          // 坏帧丢
            var regs = ModbusFrameParser.ParseReadRegisters(resp);
            if (regs.Length == 0) continue;

            double value = m.Type == "float"
                ? ModbusFrameParser.ToFloatModbus(regs[0], regs[1], m.Order)
                : regs[0];
            _last[m.PointId] = value;
            RaiseData(m.PointId, value);                               // 抬事件给采集层
        }
    }

    public override double Read(int addr) => _last.TryGetValue(addr, out var v) ? v : double.NaN;

    public override void Write(int addr, double value)
    {
        // 功能码 0x06 写单寄存器:[slave][0x06][addrHi][addrLo][valHi][valLo][CRC_L][CRC_H]
        var payload = new List<byte> { _slave, 0x06, (byte)(addr >> 8), (byte)addr,
                                       (byte)((int)value >> 8), (byte)(int)value };
        ushort crc = Crc16.Modbus(payload.ToArray());
        payload.Add((byte)(crc & 0xFF));
        payload.Add((byte)(crc >> 8));
        _port!.Write(payload.ToArray(), 0, payload.Count);
    }

    public sealed record RegisterMap(int PointId, ushort Address, string Type);
}

⚠️ 易错点: - Stop() 必须 Wait(500):不然后台任务还在读 _port,你已 Close(),抛 IOException - Start() 重入保护:if (_loop != null) return 防 Connect() 被调两次起两个循环 - 等响应用 Thread.Sleep(10) + 超时 1000ms:不要 _port.Read() 阻塞,串口没数据会卡死 - RaiseData 触发的事件在后台线程,UI 更新要 Dispatcher.Invoke(WPF 必踩) - 浮点字节序:现场最常见 CDAB(字交换),不能假设 ABCD,一定要抓帧确认

public class RelayCommand : ICommand

B11. 手写 PointStore 内存索引 + SQLite 落库(⏱️ 15 分钟)

题目:实现 PointStore,提供 AddOrUpdate(point) 同步刷新内存索引 + 异步落 SQLite;QueryHistoryAsync(pointId, from, to) 查历史。

🎯 面试官想听到:① 双轨设计:内存索引服务实时路径(不阻塞 IO),SQLite 服务历史查询;② SQLite 单写者约束:用 Channel<T> 串行化所有写;③ IDbContextFactory + await using:每条写入独立 DbContext。④ 采集线程不阻塞:写库通过 Channel 解耦。

✅ 标准答案:核心矛盾——采集线程同步调 AddOrUpdate,但 SQLite 写盘慢,直接 await db.SaveChangesAsync() 会把采集链路也拖慢,而且 SQLite 是单写者(并发写直接抛 SQLiteException: database is locked)。解法:AddOrUpdate 内部 ① lock(_gate) 同步更新内存索引 + Dictionary<int, SensorPoint> + List<SensorPoint>(给 UI 和 GetAlarms 用);② _writeQueue.Writer.TryWrite(record) 把写库任务塞 Channel。后台 _writePump 是 await foreach(var rec in reader.ReadAllAsync()) 串行消费,SingleReader=true 让 Channel 内部无锁优化。pump 里 await using var db = factory.CreateDbContextAsync() → db.Add + SaveChangesAsync。落盘失败不抛(只吞),因为实时路径已用内存索引服务了,不会因为磁盘满让采集挂。前端类比:IndexedDB + 内存 Map 双写,或 Redux store + localStorage。

💻 关键代码(对照 DAQMonitor/Core/Store/PointStore.cs):

public class PointStore : IDisposable
{
    private readonly List<SensorPoint> _points = new();
    private readonly Dictionary<int, SensorPoint> _byId = new();
    private readonly object _gate = new();

    private readonly IDbContextFactory<AppDb> _dbFactory;
    private readonly System.Threading.Channels.Channel<SensorRecord> _writeQueue =
        System.Threading.Channels.Channel.CreateUnbounded<SensorRecord>(
            new() { SingleReader = true, SingleWriter = false });
    private readonly Task _writePump;
    private volatile bool _disposed;

    public PointStore(IDbContextFactory<AppDb> factory)
    {
        _dbFactory = factory;
        _writePump = Task.Run(PumpWritesAsync);
    }

    // 采集线程调用:同步刷内存 + 异步落盘(不阻塞采集)
    public void AddOrUpdate(SensorPoint p)
    {
        lock (_gate)
        {
            _byId[p.Id] = p;
            var idx = _points.FindIndex(x => x.Id == p.Id);
            if (idx >= 0) _points[idx] = p;
            else _points.Add(p);
        }
        if (!_disposed) _writeQueue.Writer.TryWrite(SensorRecord.FromPoint(p));
    }

    public SensorPoint? Get(int id) { lock (_gate) return _byId.TryGetValue(id, out var p) ? p : null; }
    public IReadOnlyList<SensorPoint> GetAll() { lock (_gate) return _points.ToList(); }

    // 历史查询走 SQLite
    public async Task<List<SensorPoint>> QueryHistoryAsync(int pointId, DateTime from, DateTime to, CancellationToken ct = default)
    {
        await using var db = await _dbFactory.CreateDbContextAsync(ct);
        var rows = await db.Records.AsNoTracking()
            .Where(r => r.PointId == pointId && r.Time >= from && r.Time <= to)
            .OrderBy(r => r.Time)
            .ToListAsync(ct);
        return rows.ConvertAll(r => r.ToPoint());
    }

    // 单消费者:串行写,满足 SQLite 单写者
    private async Task PumpWritesAsync()
    {
        var reader = _writeQueue.Reader;
        try
        {
            await foreach (var rec in reader.ReadAllAsync())
            {
                if (_disposed) break;
                try
                {
                    await using var db = await _dbFactory.CreateDbContextAsync();
                    db.Records.Add(rec);
                    await db.SaveChangesAsync();
                }
                catch { /* 落盘失败不阻断采集 */ }
            }
        }
        catch { }
    }

    public Task FlushAsync(TimeSpan? timeout = null)
    {
        _writeQueue.Writer.TryComplete();
        return _writePump.WaitAsync(timeout ?? TimeSpan.FromSeconds(5));
    }

    public void Dispose()
    {
        if (_disposed) return;
        _disposed = true;
        _writeQueue.Writer.TryComplete();
        try { _writePump.Wait(TimeSpan.FromSeconds(2)); } catch { }
    }
}

⚠️ 易错点: - 不要直接 AddDbContext + Singleton:DbContext 并发炸(参 C5) - Channel 必须 SingleReader=true:否则内部加锁,pump 单消费者场景白白损失性能 - AddOrUpdate 不能 await:采集线程是同步循环,改 Task 会污染整条链路 - _disposed 必须 volatile:pump 在另一线程读,主线程写,避免重排 - FlushAsync 测试必调:不然 pump 还在跑测试就退出,丢点 + DbContext 泄漏

🎤 面试官追问: - Q: 高频写(每秒 1000 点)SQLite 顶得住吗? A:单条 SaveChangesAsync 撑不住,改批量——pump 里 BatchBlock 攒 100 条/200ms 一批,用 db.AddRangeRange + SaveChanges,性能提升 10-50 倍。或换 LiteDB / 不落历史只留内存环形缓冲。 - Q: 内存索引和 SQLite 不一致怎么办? static IAsyncPolicy<HttpResponseMessage> GetRetryPolicy()
{
    return HttpPolicyExtensions
        .HandleTransientHttpError()                       // 5xx + 408
        .OrResult(r => r.StatusCode == System.Net.HttpStatusCode.RequestTimeout)
        .WaitAndRetryAsync(
            retryCount: 3,
            sleepDurationProvider: attempt => TimeSpan.FromMilliseconds(Math.Pow(2, attempt) * 200),
            onRetryAsync: (outcome, delay, attempt, ctx) =>
            {
                // 注入 ILogger 上报,生产必加
                return Task.CompletedTask;
            });
}

static IAsyncPolicy<HttpResponseMessage> GetCircuitBreakerPolicy()
{
    return HttpPolicyExtensions
        .HandleTransientHttpError()
        .AdvancedCircuitBreakerAsync(
            failureThreshold: 0.5,                        // 50% 失败率触发
            samplingDuration: TimeSpan.FromSeconds(30),   // 30s 采样窗口
            minimumThroughput: 10,                        // 至少 10 次请求才统计
            durationOfBreak: TimeSpan.FromSeconds(30));   // 熔断 30s
}

    public ApiService(HttpClient http) => _http = http;   // Factory 自动注入带策略的 client

using MQTTnet;
using MQTTnet.Protocol;
using MQTTnet.Client;

public sealed class MqttClientService : IAsyncDisposable
{
    private readonly IMqttClient _client = new MqttFactory().CreateMqttClient();
    private readonly string _brokerHost;

    public event Action<string, ReadOnlyMemory<byte>>? MessageReceived;

    public MqttClientService(string brokerHost) => _brokerHost = brokerHost;

    public async Task ConnectAsync(CancellationToken ct = default)
    {
        var options = new MqttClientOptionsBuilder()
            .WithClientId($"daq-{Environment.MachineName}-{Guid.NewGuid():N}".Substring(0, 20))
            .WithTcpServer(_brokerHost, 1883)
            .WithCredentials("user", "pass")
            .WithKeepAlivePeriod(TimeSpan.FromSeconds(30))
            .WithKeepAliveSendInterval(TimeSpan.FromSeconds(15))
            .WithAutoReconnectDelay(TimeSpan.FromSeconds(2))      // 自动重连
            .WithCleanSession(false)                              // 持久会话:断线期间的消息重连后补发
            .Build();

        _client.ApplicationMessageReceivedAsync += OnMessageAsync;
        _client.DisconnectedAsync += OnDisconnectedAsync;

        await _client.ConnectAsync(options, ct);

        await _client.SubscribeAsync(new MqttClientSubscribeOptionsBuilder()
            .WithTopicFilter(f => f.WithTopic("device/+/data")     // + = 单层通配
                                   .WithAtLeastOnceQualityOfService())
            .WithTopicFilter(f => f.WithTopic("alarm/#")           // # = 多层通配
                                   .WithAtLeastOnceQualityOfService())
            .Build(), ct);
    }

    private Task OnMessageAsync(MqttApplicationMessageReceivedEventArgs e)
    {
        // 不要在这里 await 长任务!会阻塞 MQTT 内部循环
        MessageReceived?.Invoke(e.ApplicationMessage.Topic, e.ApplicationMessage.Payload);
        return Task.CompletedTask;
    }

    private Task OnDisconnectedAsync(MqttClientDisconnectedEventArgs e)
    {
        // AutoReconnect 已开,这里只做日志
        return Task.CompletedTask;
    }

    public async Task PublishAsync(string topic, ReadOnlyMemory<byte> payload,
        MqttQualityOfServiceLevel qos = MqttQualityOfServiceLevel.AtLeastOnce,
        bool retain = false, CancellationToken ct = default)
    {
        if (!_client.IsConnected) return;                         // 离线丢弃,生产要加本地队列

        var msg = new MqttApplicationMessageBuilder()
            .WithTopic(topic)
            .WithPayload(payload)
            .WithQualityOfServiceLevel(qos)
            .WithRetainFlag(retain)
            .Build();
        await _client.PublishAsync(msg, ct);
    }

    public async ValueTask DisposeAsync()
    {
        _client.ApplicationMessageReceivedAsync -= OnMessageAsync;
        if (_client.IsConnected) await _client.DisconnectAsync();
        _client.Dispose();
    }
}

using S7;

public sealed class PlcDevice : DeviceBase
{
    public sealed record PlcMap(int PointId, string DbAddress);   // "DB1.DBW0"

    private readonly string _ip;
    private readonly List<PlcMap> _maps;
    private Plc? _plc;
    private CancellationTokenSource? _cts;
    private Task? _loop;
    private readonly Dictionary<int, double> _last = new();

    public PlcDevice(int id, string name, string ip, IEnumerable<PlcMap> maps) : base(id, name)
    {
        _ip = ip;
        _maps = maps.ToList();
    }

    public override void Connect()
    {
        State = DeviceState.Connecting;
        _plc = new Plc(CpuType.S71200, _ip, rack: 0, slot: 1);
        _plc.Open();                                            // 阻塞调用,生产应包 Task.Run
        Start();
        State = DeviceState.Online;
    }

    public override void Disconnect()
    {
        Stop();
        try { _plc?.Close(); } catch { }
        State = DeviceState.Offline;
    }

    private void Start()
    {
        if (_loop is not null) return;
        _cts = new CancellationTokenSource();
        var token = _cts.Token;
        _loop = Task.Run(async () =>
        {
            try
            {
                while (!token.IsCancellationRequested)
                {
                    Tick();
                    await Task.Delay(500, token);
                }
            }
            catch (OperationCanceledException) { }
        }, token);
    }

    private void Stop()
    {
        _cts?.Cancel();
        try { _loop?.Wait(500); } catch { }
        _cts?.Dispose(); _cts = null; _loop = null;
    }

    private void Tick()
    {
        foreach (var m in _maps)
        {
            try
            {
                // S7.Net Read 是同步阻塞,真实工程应 Task.Run 包,或用 async 库
                var raw = (short)_plc!.Read(m.DbAddress);       // DB1.DBW0 → Int16
                if (_plc.LastErrorCode != 0) continue;          // IsConnected 不可全信!

                double v = raw;
                _last[m.PointId] = v;
                RaiseData(m.PointId, v);
            }
            catch { /* 单点失败不阻断其他点位 */ }
        }
    }

    public override double Read(int addr)
        => _last.TryGetValue(addr, out var v) ? v : double.NaN;

    public override void Write(int addr, double value)
    {
        if (_plc?.IsConnected != true) return;
        // DB1.DBW0 = addr,写 Int16(Word)
        var map = _maps.FirstOrDefault(m => m.PointId == addr);
        if (map is null) return;
        _plc.Write(map.DbAddress, (short)value);
    }
}

B16. 手写 TcpDevice 粘包处理(状态机)(⏱️ 15 分钟)

题目:实现 TCP 长连接设备的接收循环。帧格式 [AA 55][LEN_LO][LEN_HI][payload][CRC_LO][CRC_HI],处理:① 半包(收到的字节不够一帧);② 粘包(多条帧粘在一起);③ 头不对齐(乱码,需要重新同步);④ 心跳超时检测 + 自动重连。

✅ 标准答案:TCP 是字节流,无消息边界,接收方必须自己拼帧。架构是:外层重连循环(while !ct.IsCancellationRequested → ConnectOnce → ReceiveLoop → 出错后 DelayBackoff);接收循环(ReceiveAsync(seg) → buffer.AddRange → DrainBuffer)→ DrainBuffer 在 while(buffer.Count>0) 里循环调 TcpFrameParser.TryParse(span, out payload, out frameLen, out needResync),true → 消费 frameLen 字节、调 HandlePayload;false 且 needResync → buffer.RemoveAt(0) 丢 1 字节重同步;false 且不 needResync(数据不够) → break 等下次 Receive。心跳并行:Task.Delay(10s) → SendAsync(heartbeat),断线检测:if (UtcNow - lastRecv > 30s) return。前端类比:WebSocket + 自己写 protobuf 长度前缀解析的 chunked buffer。

💻 关键代码(对照 DAQMonitor/Core/Devices/TcpDevice.cs):

public sealed class TcpDevice : DeviceBase
{
    private const int HeartbeatIntervalMs = 10_000;
    private const int OfflineTimeoutMs = 30_000;
    private static readonly int[] BackoffMs = { 1000, 2000, 4000, 8000, 16000 };

    private readonly string _host;
    private readonly int _port;
    private Socket? _socket;
    private CancellationTokenSource? _cts;
    private Task? _loop;
    private readonly byte[] _rx = new byte[4096];
    private readonly ConcurrentDictionary<int, double> _last = new();

    public TcpDevice(int id, string name, string host, int port) : base(id, name)
    {
        _host = host; _port = port;
    }

    public override void Connect()
    {
        if (State == DeviceState.Online) return;
        State = DeviceState.Connecting;
        if (_loop is not null) return;
        _cts = new CancellationTokenSource();
        _loop = Task.Run(() => RealLoop(_cts.Token), _cts.Token);
    }

    public override void Disconnect() { Stop(); State = DeviceState.Offline; }

    private async Task RealLoop(CancellationToken ct)
    {
        int backoffIdx = 0;
        while (!ct.IsCancellationRequested)
        {
            try
            {
                if (!ConnectOnce())
                {
                    await DelayBackoff(ct, backoffIdx);
                    backoffIdx = Math.Min(backoffIdx + 1, BackoffMs.Length - 1);
                    continue;
                }
                backoffIdx = 0;
                State = DeviceState.Online;

                using var heartbeatCts = CancellationTokenSource.CreateLinkedTokenSource(ct);
                _ = HeartbeatLoop(heartbeatCts.Token);          // 并行心跳

                await ReceiveLoop(ct);                          // 正常退出=掉线
                heartbeatCts.Cancel();
            }
            catch (OperationCanceledException) { break; }
            catch (SocketException) { /* 走重连 */ }
            catch (IOException) { /* 走重连 */ }
            finally { CloseSocket(); State = DeviceState.Connecting; }

            if (ct.IsCancellationRequested) break;
            await DelayBackoff(ct, backoffIdx);
            backoffIdx = Math.Min(backoffIdx + 1, BackoffMs.Length - 1);
        }
    }

    private bool ConnectOnce()
    {
        try
        {
            CloseSocket();
            _socket = new Socket(AddressFamily.InterNetwork, SocketType.Stream, ProtocolType.Tcp)
            {
                ReceiveTimeout = OfflineTimeoutMs,
                SendTimeout = 5000
            };
            _socket.Connect(_host, _port);
            return true;
        }
        catch (SocketException) { return false; }
    }

    private async Task ReceiveLoop(CancellationToken ct)
    {
        var buffer = new List<byte>(4096);                      // 滚动缓冲
        var seg = new byte[4096];
        DateTime lastRecv = DateTime.UtcNow;

        while (!ct.IsCancellationRequested && _socket?.Connected == true)
        {
            int n;
            try { n = await _socket.ReceiveAsync(new ArraySegment<byte>(seg), SocketFlags.None, ct); }
            catch (SocketException) { return; }
            if (n == 0) return;                                 // 对端关闭
            lastRecv = DateTime.UtcNow;

            buffer.AddRange(seg.AsSpan(0, n));
            DrainBuffer(buffer);                                // 切出所有完整帧

            if ((DateTime.UtcNow - lastRecv).TotalMilliseconds > OfflineTimeoutMs) return;
        }
    }

    private void DrainBuffer(List<byte> buffer)
    {
        while (buffer.Count > 0)
        {
            var span = CollectionsMarshal.AsSpan(buffer);
            if (!TcpFrameParser.TryParse(span, out var payload, out int frameLen, out bool needResync))
            {
                if (needResync) buffer.RemoveAt(0);             // 头不对齐:丢 1 字节重同步
                break;                                          // 数据不够:等下次 Receive
            }
            HandlePayload(payload);
            buffer.RemoveRange(0, frameLen);
        }
    }

    private void HandlePayload(byte[] payload)
    {
        // 业务解析:payload[0] 功能码,payload[1..] 数据
        // 例:0x01 = 多点上报,[0x01][N][N×(addr:2, val:4 float LE)]
        if (payload.Length < 2 || payload[0] != 0x01) return;
        int n = payload[1];
        for (int i = 0; i < n; i++)
        {
            int off = 2 + i * 6;
            if (off + 6 > payload.Length) break;
            int pid = payload[off] | (payload[off + 1] << 8);
            double val = BitConverter.ToSingle(payload, off + 2);
            _last[pid] = val;
            RaiseData(pid, Math.Round(val, 3));
        }
    }

    private async Task HeartbeatLoop(CancellationToken ct)
    {
        var frame = TcpFrameParser.BuildFrame(new byte[] { 0x02 });   // 0x02 = 心跳
        while (!ct.IsCancellationRequested && _socket?.Connected == true)
        {
            try { await _socket!.SendAsync(new ArraySegment<byte>(frame), SocketFlags.None, ct); }
            catch (SocketException) { return; }
            try { await Task.Delay(HeartbeatIntervalMs, ct); }
            catch (OperationCanceledException) { return; }
        }
    }

    private static async Task DelayBackoff(CancellationToken ct, int idx)
    {
        int ms = BackoffMs[Math.Min(idx, BackoffMs.Length - 1)];
        try { await Task.Delay(ms, ct); } catch (OperationCanceledException) { }
    }

    private void CloseSocket()
    {
        try { _socket?.Shutdown(SocketShutdown.Both); } catch { }
        try { _socket?.Close(); } catch { }
        _socket = null;
    }

    public override double Read(int addr) => _last.TryGetValue(addr, out var v) ? v : double.NaN;
    public override void Write(int addr, double value) { /* 同 build frame + send */ }

    private void Stop()
    {
        try { _cts?.Cancel(); } catch { }
        try { _loop?.Wait(1000); } catch { }
        CloseSocket();
        _cts?.Dispose(); _cts = null; _loop = null;
    }
}

⚠️ 易错点: - n == 0 是对端关闭:ReceiveAsync 返回 0 表示 FIN,不是错误,必须 return 让重连循环接手 - buffer.RemoveAt(0) 是 O(N):高频场景性能炸,生产用 ArrayPool<byte> + 环形缓冲 / MemoryStream 滑窗(参 C7 修正) - 心跳和接收不要互相 await:心跳 Task.Delay(10s) 阻塞 ReceiveLoop 会让心跳期间收不到数据 → 用并行 Task + LinkedTokenSource - 重连退避要 cap:BackoffMs.Last() 是上限,不要无限翻倍(Math.Pow(2, 20) 会溢出) - Shutdown(Both) 必须在 try-catch:对端已经关了你再 Shutdown 抛 SocketException,直接吞

🎯 面试官想听到:① 类型键 Dictionary<Type, List<Delegate>>;② 弱引用避免内存泄漏(VM 订阅但没退订时,VM 不会泄漏);③ 线程安全 lock。

💻 关键代码:

public interface IEventAggregator
{
    void Subscribe<T>(Action<T> handler);
    void Unsubscribe<T>(Action<T> handler);
    void Publish<T>(T message);
}

public sealed class EventAggregator : IEventAggregator
{
    private readonly Dictionary<Type, List<WeakDelegate>> _handlers = new();
    private readonly object _gate = new();

    public void Subscribe<T>(Action<T> handler)
    {
        lock (_gate)
        {
            if (!_handlers.TryGetValue(typeof(T), out var list))
                _handlers[typeof(T)] = list = new();
            list.Add(new WeakDelegate(handler));
        }
    }

    public void Unsubscribe<T>(Action<T> handler)
    {
        lock (_gate)
        {
            if (_handlers.TryGetValue(typeof(T), out var list))
                list.RemoveAll(w => !w.IsAlive || w.Matches(handler));
        }
    }

    public void Publish<T>(T message)
    {
        List<WeakDelegate>? snapshot;
        lock (_gate)
        {
            if (!_handlers.TryGetValue(typeof(T), out var list)) return;
            snapshot = list.ToList();
        }
        foreach (var w in snapshot)
        {
            if (w.TryInvoke(message) is false)   // 已被 GC
            {
                lock (_gate) _handlers[typeof(T)].Remove(w);
            }
        }
    }

    // 弱引用包装:订阅者 GC 后自动失效
    private sealed class WeakDelegate
    {
        private readonly WeakReference _target;
        private readonly MethodInfo _method;
        private readonly Type _argType;
        public bool IsAlive => _target.IsAlive;

        public WeakDelegate(Delegate d)
        {
            _target = new WeakReference(d.Target);
            _method = d.Method;
            _argType = d.Method.GetParameters()[0].ParameterType;
        }

        public bool? TryInvoke(object? arg)
        {
            var t = _target.Target;
            if (t is null) return false;
            _method.Invoke(t, new[] { arg });
            return true;
        }

        public bool Matches(Delegate d) => ReferenceEquals(_target.Target, d.Target) && _method == d.Method;
    }
}

⚠️ 易错点: - 弱引用 + Lambda 不兼容(Lambda 没有强目标,会被立即 GC),必须具名方法 - Publish 内部不要 lock:委托执行可能耗时,锁会阻塞其他 Publish/Subscribe - 跨线程 Publish 要 Dispatcher.Invoke(WPF) 或约定都在 UI 线程

public sealed class IpAllowListMiddleware
{
    private readonly RequestDelegate _next;
    private readonly List<(IPAddress Base, int Mask)> _allowed;
    private readonly ILogger<IpAllowListMiddleware> _log;

    public IpAllowListMiddleware(RequestDelegate next, IConfiguration cfg,
        ILogger<IpAllowListMiddleware> log)
    {
        _next = next;
        _log = log;
        _allowed = cfg.GetSection("AllowedIpCidrs").Get<List<string>>()
            ?? new();
    }

    public async Task InvokeAsync(HttpContext ctx)
    {
        var clientIp = ctx.Connection.RemoteIpAddress;
        if (clientIp is null || !IsAllowed(clientIp))
        {
            _log.LogWarning("拒绝访问: {Ip} {Path}", clientIp, ctx.Request.Path);
            ctx.Response.StatusCode = 403;
            await ctx.Response.WriteAsync("Forbidden");
            return;
        }
        await _next(ctx);
    }

    private bool IsAllowed(IPAddress ip)
    {
        foreach (var (baseIp, mask) in _allowed.Select(ParseCidr))
        {
            if (IpInCidr(ip, baseIp, mask)) return true;
        }
        return false;
    }

    private static (IPAddress Base, int Mask) ParseCidr(string cidr)
    {
        var parts = cidr.Split('/');
        return (IPAddress.Parse(parts[0]), int.Parse(parts[1]));
    }

    private static bool IpInCidr(IPAddress ip, IPAddress baseIp, int mask)
    {
        if (ip.AddressFamily != baseIp.AddressFamily) return false;
        var ipBytes = ip.GetAddressBytes();
        var baseBytes = baseIp.GetAddressBytes();
        int fullBytes = mask / 8;
        int remBits = mask % 8;
        for (int i = 0; i < fullBytes; i++)
            if (ipBytes[i] != baseBytes[i]) return false;
        if (remBits > 0)
        {
            int maskByte = 0xFF << (8 - remBits);
            if ((ipBytes[fullBytes] & maskByte) != (baseBytes[fullBytes] & maskByte)) return false;
        }
        return true;
    }
}

题目:工业场景"配方"= 一组参数集。要求:LoadAsync(name) 加载、ActivateAsync(name) 激活、激活失败自动回滚到上一个;每次切换记录历史。

public sealed record Recipe(string Name, Dictionary<string, double> Parameters);

public sealed class RecipeManager
{
    private readonly Dictionary<string, Recipe> _recipes = new();
    private readonly Stack<Recipe> _history = new();
    private Recipe? _current;
    private readonly IDevice _device;
    private readonly object _gate = new();

    public Recipe? Current { get { lock (_gate) return _current; } }

    public RecipeManager(IDevice device) => _device = device;

    public void Register(Recipe r) { lock (_gate) _recipes[r.Name] = r; }

    public async Task<bool> ActivateAsync(string name)
    {
        Recipe? recipe;
        Recipe? previous;
        lock (_gate)
        {
            if (!_recipes.TryGetValue(name, out recipe)) return false;
            previous = _current;
        }

        try
        {
            // 下发每个参数到设备
            foreach (var (key, value) in recipe.Parameters)
            {
                _device.Write(HashAddr(key), value);   // 简化:key → addr 映射
                await Task.Delay(50);                   // 给设备喘息
            }

            lock (_gate)
            {
                if (previous is not null) _history.Push(previous);
                _current = recipe;
            }
            return true;
        }
        catch (Exception)
        {
            // 失败回滚:重新下发 previous
            if (previous is not null)
            {
                foreach (var (key, value) in previous.Parameters)
                {
                    try { _device.Write(HashAddr(key), value); } catch { }
                }
            }
            return false;
        }
    }

    public async Task<bool> RollbackAsync()
    {
        Recipe? prev;

public static class EngineeringConverter
{
    // 4-20mA → 0-100℃:raw ∈ [0, 65535] → eng ∈ [0, 100]
    public static double Linear(double raw, double rawMin, double rawMax, double engMin, double engMax)
    {
        double span = rawMax - rawMin;
        if (Math.Abs(span) < double.Epsilon) return engMin;   // 防除零
        double ratio = (raw - rawMin) / span;
        return engMin + ratio * (engMax - engMin);
    }

    // 非线性查表(PT100 分度表)
    public static double Lookup(double raw, SortedList<double, double> table)
    {
        if (table.Count == 0) throw new ArgumentException("分度表空");
        if (raw <= table.Keys[0]) return table.Values[0];
        if (raw >= table.Keys[^1]) return table.Values[^1];

        int idx = Bisect(table.Keys, raw);
        double x0 = table.Keys[idx - 1], x1 = table.Keys[idx];
        double y0 = table.Values[idx - 1], y1 = table.Values[idx];
        return y0 + (raw - x0) / (x1 - x0) * (y1 - y0);
    }

    private static int Bisect(IReadOnlyList<double> keys, double target)
    {
        int lo = 0, hi = keys.Count;
        while (lo < hi)
        {
            int mid = (lo + hi) >> 1;
            if (keys[mid] <= target) lo = mid + 1; else hi = mid;
        }
        return lo;
    }

    public enum ByteOrder { ABCD, CDAB, BADC, DCBA }

    public static byte[] Swap(byte[] bytes, ByteOrder order) => order switch
    {
        ByteOrder.ABCD => bytes,
        ByteOrder.CDAB => new[] { bytes[2], bytes[3], bytes[0], bytes[1] },   // 字交换(最常见)
        ByteOrder.BADC => new[] { bytes[1], bytes[0], bytes[3], bytes[2] },
        ByteOrder.DCBA => new[] { bytes[3], bytes[2], bytes[1], bytes[0] },
        _ => throw new ArgumentOutOfRangeException(nameof(order))
    };

    public static float ToFloat(byte[] bytes, ByteOrder order = ByteOrder.ABCD)
    {
        var ordered = Swap(bytes, order);
        if (BitConverter.IsLittleEndian) Array.Reverse(ordered);   // ABCD 是大端
        return BitConverter.ToSingle(ordered, 0);
    }
}

⚠️ 易错点: - 除零:rawMax == rawMin 必须特判 - 字节序:必须抓帧确认,不要假设 ABCD;现场最常见 CDAB(字交换) - 查表 SortedList 内存占用大,可改成二进制分度表文件 lazy load

public sealed class PerformanceCounter : IDisposable
{
    private long _totalRequests;
    private long _totalErrors;
    private long _totalLatencyTicks;   // 总耗时(tick)
    private DateTime _windowStart = DateTime.UtcNow;
    private readonly Timer _reporter;

    public PerformanceCounter(TimeSpan reportInterval)
    {
        _reporter = new Timer(_ => ReportAndReset(), null, reportInterval, reportInterval);
    }

    public void RecordRequest(double latencyMs, bool success)
    {
        Interlocked.Increment(ref _totalRequests);
        if (!success) Interlocked.Increment(ref _totalErrors);
        Interlocked.Add(ref _totalLatencyTicks, (long)(latencyMs * TimeSpan.TicksPerMillisecond));
    }

    private void ReportAndReset()
    {
        var now = DateTime.UtcNow;
        var elapsed = (now - _windowStart).TotalSeconds;
        if (elapsed <= 0) return;

        long reqs = Interlocked.Exchange(ref _totalRequests, 0);
        long errs = Interlocked.Exchange(ref _totalErrors, 0);
        long ticks = Interlocked.Exchange(ref _totalLatencyTicks, 0);
        _windowStart = now;

        double qps = reqs / elapsed;
        double avgLatencyMs = reqs > 0 ? ticks / (double)TimeSpan.TicksPerMillisecond / reqs : 0;
        double errorRate = reqs > 0 ? (double)errs / reqs : 0;

        // 推送到 Prometheus(用 prometheus-net)
        // Metrics.Qps.WithLabels("api").Set(qps);
        Console.WriteLine($"QPS={qps:F1} AvgLatency={avgLatencyMs:F1}ms ErrorRate={errorRate:P1}");
    }

    public void Dispose() => _reporter.Dispose();
}

⚠️ 易错点: - Interlocked 而不是 lock,高并发下 lock 会拖慢 - Interlocked.Exchange 原子重置,避免上报与计数竞态 - 窗口期内 0 请求要特判(除零)

public sealed class LazyCache<TKey, TValue> where TKey : notnull
{
    private readonly ConcurrentDictionary<TKey, Lazy<Task<TValue>>> _cache = new();
    private readonly Func<TKey, CancellationToken, Task<TValue>> _factory;

    public LazyCache(Func<TKey, CancellationToken, Task<TValue>> factory) => _factory = factory;

    public Task<TValue> GetOrAddAsync(TKey key, CancellationToken ct = default)
    {
        // 关键:用 Lazy<Task<TValue>>,ConcurrentDictionary 的 GetOrAdd 只保证单次添加
        // 不会重复调 factory
        return _cache.GetOrAdd(key, k => new Lazy<Task<TValue>>(() => _factory(k, ct)))
                     .Value;     // Lazy.Value 线程安全,多个线程同时拿只触发一次
    }

    public bool TryRemove(TKey key) => _cache.TryRemove(key, out _);
    public void Clear() => _cache.Clear();
}

// 用法

{
    return await _httpClient.GetFromJsonAsync<User>($"/api/users/{id}", ct)
           ?? throw new KeyNotFoundException(id);
});

// 多线程并发请求 user-1,只发一次 HTTP

var u2 = await cache.GetOrAddAsync("user-1");   // 命中缓存

    {

        });

        _defaultOptions = new MemoryCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(30),  // 绝对过期
            SlidingExpiration = TimeSpan.FromMinutes(5),                 // 滑动过期
            Size = 1                                                      // 必须配合 SizeLimit
        };
    }

    public T GetOrCreate<T>(string key, Func<T> factory, TimeSpan? ttl = null)
    {
        var opts = ttl is null ? _defaultOptions : new MemoryCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = ttl,
            Size = 1,
            PostEvictionCallbacks =
            {
                new PostEvictionCallbackRegistration
                {
                    EvictionCallback = (k, v, reason, state) =>
                        Console.WriteLine($"驱逐 {k}: {reason}")
                }
            }
        };

        // GetOrCreate 是原子操作
        return _cache.GetOrCreate(key, entry =>
        {
            entry.SetOptions(opts);
            return factory();
        });
    }

    public void Remove(string key) => _cache.Remove(key);
}

GetRef(0).X = 99;

C7. TCP 缓冲区泄漏

// 半包留到下次拼接
var keep = new MemoryStream();
buf.CopyTo(keep);
buf.SetLength(0);
keep.CopyTo(buf);

Bug:MemoryStream.CopyTo byte-by-byte 循环,高频小包性能炸(每帧 GC 压力 + 10 倍 CPU)。

修复:用 Array.Copy + 重置 Position:

int remaining = (int)(buf.Length - buf.Position);
if (remaining > 0)
    Array.Copy(buf.GetBuffer(), buf.Position, buf.GetBuffer(), 0, remaining);
buf.SetLength(remaining);
buf.Position = 0;

详 M11 修正版。

C8. 闭包捕获循环变量

for (int i = 0; i < 5; i++)
{
    Task.Run(() => Console.WriteLine(i));   // ← 全打印 5!
}

Bug:Lambda 捕获的是变量 i 的引用(不是值),循环结束 i=5,5 个 Task 全打印 5。

修复(C# 5+ 已修,但老代码可能踩):

for (int i = 0; i < 5; i++)
{
    var local = i;   // 局部副本
    Task.Run(() => Console.WriteLine(local));
}

C9. async lambda 没等待

public async Task ProcessAllAsync(IEnumerable<int> ids)
{
    foreach (var id in ids)
    {
        ProcessAsync(id);   // ← 没 await,fire-and-forget
    }
}

Bug:ProcessAsync 没 await,任务发出但没等结果,异常被吞。

修复(两种):

// 1. 串行
foreach (var id in ids) await ProcessAsync(id);

// 2. 并行
await Task.WhenAll(ids.Select(ProcessAsync));

C10. 字节序搞反

byte[] resp = { 0x01, 0x03, 0x04, 0x00, 0x0A, 0x00, 0x14, 0xC4, 0x0B };
//                                ↑ 寄存器1   ↑ 寄存器2

// 错误:小端拼
ushort reg1 = (ushort)(resp[3] | (resp[4] << 8));   // 0x0A00 = 2560(错!)

// 正确:大端拼(Modbus 寄存器大端)
ushort reg1 = (ushort)((resp[3] << 8) | resp[4]);   // 0x000A = 10(对)

Bug:Modbus 寄存器是大端,但 Modbus CRC 是小端,别搞反。
