依赖与授权 · 免费开源清单（及付费框架的免费替代）

一句话结论：DAQMonitor 这条学习路线全程零付费——我们刻意选的全部是 MIT/Apache/BSD 等开源协议或微软官方免费的库。你学完就能零成本做企业项目，不用担心"没买授权不能用"。 工业现场确实有一批商业控件/库很流行，但它们都有免费替代；本文把常见付费项 + 免费替代 + "哪些该自己写"一次说清。

🔴 二、工业常见的「付费框架」与「免费替代」对照

付费项（行业常见） 典型产品 免费替代（我们路线怎么覆盖）
WPF/WinForms 控件套件 DevExpress、Telerik UI、ComponentOne、Infragistics HandyControl + MaterialDesignInXamlToolkit + 自绘自定义控件（本项目已手写 GaugeControl/StatusDot）
机器视觉库 Halcon、VisionPro（很贵） OpenCvSharp / EmguCV / YOLO(OnnxRuntime) —— 加分项，非必
采集卡驱动/SDK NI-DAQmx（需 NI 硬件 + 授权） 研华/凌华/国产板卡自带免费驱动；或用 Modbus/TCP 走网卡绕开采集卡（我们的主线就是这思路）
报表组件 Crystal Reports、ActiveReports、FastReport(商业版) ClosedXML（已用）+ QuestPDF(开源) + Microsoft ReportViewer(RDLC 免费)
商业 OPC 服务器 Kepware、Matrikon(部分收费) OPC Foundation UA .NETStandard（官方开源）+ 各 PLC 厂免费 OPC 服务
数值/算法运行时 MATLAB Runtime Math.NET Numerics（开源免费）
虚拟串口（调试用） VSPD（商业，可试用） com0com（开源免费，本项目硬件替代方案已讲）

看清一点：付费控件大多是"开箱即用的美观套件 + 官方支持"。但核心功能（表格/图表/报表/通信）免费库都能做，且自己写的控件无授权费、可深度定制、出 bug 能进源码调试——这正是我们"边做边用自定义控件"的底层理由。

🛠️ 三、自定义组件的边界：哪些该自己写，哪些用现成

该自己写/自绘（无好免费件 或 强定制） 该用现成免费库（重复造轮子不值）
行业专用仪表（压力表/温度计/流量表） 通用图表曲线 → LiveCharts
设备状态灯/脉冲动画 → 本项目 StatusDot 大数据表格 → DataGrid(WPF 自带)
工程量刻度表/指针表 → 本项目 GaugeControl Excel/PDF 报表 → ClosedXML/QuestPDF
自研协议报文查看器 日志框架 → Serilog
LED 数码管、工艺流程动画 通信协议栈 → NModbus/S7.Net/HslCommunication

经验法则：凡是"和业务强相关、要长成公司产品一部分"的控件，自己写（一次性投入，永久免费+可控）；凡是"通用基础设施"，用成熟免费库（省时间+少 bug）。

✅ 四、给你的定心丸

  1. 简历项目 DAQMonitor 用的全是免费件，面试被问"你们用什么控件"——答"HandyControl + 自研 WPF 自定义控件（继承 Control + 依赖属性）"，比"买了 DevExpress"更显功底。
  2. 上岗后若公司买了 DevExpress/Telerik，你已有自绘基础，换商用套件只是"换个 API"，上手极快。
  3. 需要对接付费硬件（NI 卡/视觉相机）时，先看厂商有没有免费驱动/SDK——绝大多数都有，别一上来就买库。
