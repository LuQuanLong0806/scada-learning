🚀 怎么用

1零基础起步「入口·路线」里先看教练带练和实操入门，学会 dotnet CLI 建工程、跑 build/run/test。
2按序学讲义「模块讲义」M0 → M8 核心必学；学完想直接做项目，跳到「项目实践」。
3入职式开发「项目实践」拿需求单自己写 → 卡了看参考实现 → 点知识点亮牌回讲义重学。
4练习+打卡配合「练习·复习」每天 1h 代码肌肉 + 间隔重复，每节勾「打卡」自动存进度。
5边做边投「求职冲刺」对照 JD 路线图，过完 M11+M12 就能投，面中补漏。
