🚀 怎么用

1从入门起步先点「实操入门」，学会文件夹命名、用 dotnet CLI 建工程、跑 build/run/test。
2按序学模块从 M0 卡片点进去，左侧是目录，顶部是技术来源图例。
3做练习+打卡每天看讲解→按「练习阶梯」L1→L2→L3 做→勾右上「打卡」，进度自动存本地。
4卡住就说对我说「讲 Day N 的 XX」或「Day N 练习答案」，我展开讲。
5落项目每完成一个模块，把 DAQMonitor 对应代码提交 Git，作品集逐步成形。
